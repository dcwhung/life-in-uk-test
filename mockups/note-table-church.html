國教記憶法 table preview（Theme B）

英國 4 國（現有 note 用緊 → 文字）轉 table。「君主係最高領袖…」呢類長句放唔落一行，所以有 4 個寫法：
V1：3 欄 + 表下補充
記憶法：
| 國家 | 國教 | 教會 |
| England | ✓ | Church of England |
| Scotland | ✗ | Church of Scotland |
| Wales | ✗ | ✗ |
| N. Ireland | ✗ | ✗ |
• England：君主係最高領袖，坎特伯雷大主教係精神領袖；
• Scotland：Presbyterian（長老會），係國家教會，唔係國教。
V2：4 欄，備注欄可以轉行
記憶法：
| 國家 | 國教 | 教會 | 備注 |
| England | ✓ | Church of England | 君主係最高領袖，坎特伯雷大主教係精神領袖 |
| Scotland | ✗ | Church of Scotland | Presbyterian（長老會），國家教會 |
| Wales | ✗ | ✗ | |
| N. Ireland | ✗ | ✗ | |
V4：備注放入「教會」格（用 <br> 分行）
記憶法：
| 國家 | 國教 | 教會 |
| England | ✓ | Church of England<br>君主係最高領袖，坎特伯雷大主教係精神領袖 |
| Scotland | ✗ | Church of Scotland<br>Presbyterian（長老會），國家教會，唔係國教 |
| Wales | ✗ | ✗ |
| N. Ireland | ✗ | ✗ |
V3：而家嘅文字（對照）
記憶法：
England → ✓ 國教 → Church of England → 君主係最高領袖，…；
Scotland → ✗ 國教 → Church of Scotland → Presbyterian（長老會），…；
Wales → ✗ 國教 → ✗ 冇國教教會；
N. Ireland → ✗ 國教 → ✗ 冇國教教會。
