## 問題描述

舊 shell（PR3 之前嘅 `index.html`，冇 `#screenPlanGoal` / `#infoPlanRow` / `#appToast`）+ 新 js 時，`LATE_BOOT_SCRIPTS` 補載咗 `planHome.js` / `planGoal.js`。`renderPlanSettings()` 有檢查 `#infoPlanRow`、`showToast()` 有檢查 `#appToast`，但 `renderPlanCard()` 只要有 `#installBanner` 就會 create `#planCard`。撳建立卡 → `openPlanGoal()` → `showScreen('screenPlanGoal')` → `TypeError: Cannot read properties of null (reading 'contains')`（`utils.js:234`），畫面留喺主頁。

## 重現步驟

1. 用 PR tree，但 `index.html` 換做 `origin/main` 版本（QA script U6 做法）
2. localStorage `lifeuk.studyPlanPreview = true`，開 app
3. 主頁見到「Create a study plan」卡 → 撳

截圖：scratchpad `U-375-mixed-shell-preview-card.png`

## 預期結果

舊 shell 冇目標畫面時唔顯示建立卡（下次 reload 用新 shell 先出），或者撳落去唔會 throw。

## 實際結果

卡出現；撳落 pageerror，冇反應。

## 建議修正

`planEntryReady()`（或 `renderPlanCard()`）加 shell 檢查：`byId('screenPlanGoal')` 存在先當入口 ready，同 `renderPlanSettings` 檢查 `#infoPlanRow` 一致；`upgrade-test` 加「舊 shell + preview / READY → 冇卡、冇 error」。

## 解決方案（完成後填寫）

`js/screens/planHome.js`：`planShellReady()`（`#screenPlanGoal` 存在）加入 `planVisible()`，舊 cached `index.html` 冇目標畫面就唔出主頁卡、`openPlanGoal()` 直接返回；ⓘ「功能」行本身已檢查 `#infoPlanRow`。`tests/upgrade-test.js` `prePlanUiShell`：PR3 前（`4dc89b2`）`index.html` + 現行 js + preview → planHome.js 有 late boot、冇卡、`openPlanGoal()` 留喺主頁、撳 ⓘ 冇 error
