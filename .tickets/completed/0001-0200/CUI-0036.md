## 問題描述

W-067 修正（`studySyncTopHeight()`）令 `scroll-padding-top` = header + pinned block，`flashStudyFact` 用 `scrollIntoView({ block: 'nearest' })`。當張卡**高過** viewport 減 header + block 嘅空間，而且卡頂喺 block 後面、卡底喺 viewport 以下（即係用戶撳卡底「▶ 練習」時最常見嘅位置），`nearest` 按規格「兩邊都超出就唔捲」，卡頂留喺 pinned block 後面。

People tab，每個 config 嘅 55 張卡入面有幾多張高過可用空間（QA probe，v1.6.0 對照：可用空間 = viewport − header 58px）：

| viewport | 字型 | v1.6.1 可用空間 | 高過空間嘅卡（v1.6.1） | v1.6.0 |
|---|---|---|---|---|
| 320×568 en | 細 / 大 | 358 / 349px | **28 / 49** 張 | 0 / 5 張 |
| 320×568 zh-HK | 細 / 大 | 354 / 345px | **23 / 46** 張 | 0 / 4 張 |
| 360×640 en | 細 / 大 | 427 / 419px | 2 / **17** 張 | 0 / 0 |
| 360×640 zh-HK | 細 / 大 | 423 / 415px | 1 / **17** 張 | 0 / 0 |
| 390×844 | 全部 | ≥ 617px | 0 | 0 |

## 重現步驟

1. 320×568（或 360×640 大字），Study → People
2. 捲到第 7 張卡（例：#16 William the Conqueror），令佢嘅「▶ 練習」喺畫面底、卡頂喺 tab / chip block 後面
3. 撳「▶ 練習」→ 跳去最後一題 → 「↩ 返回」
4. 返到 Study：卡有 flash，但卡頂（年份 / 標題 / badge）喺 pinned block 後面（320×568 en 大字：卡頂 170px，block 底 219px）

## 根源

`flashStudyFact` 一律 `block: 'nearest'`；卡高過 scrollport（扣除 `scroll-padding-top`）時，`nearest` 唔會將卡頂帶入 view。pinned block 令細 mon 嘅 scrollport 細咗 150–165px，所以 v1.6.0 冇事嘅卡而家觸發。

## 建議修正（要用戶揀）

- **方案 A**：`flashStudyFact` 量 `el.offsetHeight > innerHeight − (header + --study-top-h)` 時用 `block: 'start'`（卡頂貼 block 底），否則照 `nearest`。Trade-off：卡底嘅「▶ 練習」會捲出畫面。
- **方案 B**：接受現狀並喺 HANDOFF 記錄（卡有 flash、▶ 位置唔變）。
- Test：`study-sticky-test` 加 320×568 en 大字 tall-card 返回 case。
