## 問題描述

`js/core/config.js` 嘅 `APP_VERSION` 決定 SW cache 名（`sw.js`：`CACHE = 'lifeuk-v' + APP_VERSION`），而 SW 係 cache-first app shell。

- `claude/charming-archimedes-hrh4wd`（CUI-0039，呢條）：`APP_VERSION = '2.1.1'`（merge `main` v2.1.0 時由 2.0.6 升，review v2.0.6 W-076）
- `origin/fix/quiz/back-to-entry`（另一 session，做題返回入口；已 merge `main` v2.1.0，e50ddd8）：都係 `APP_VERSION = '2.1.1'`

兩條 branch 嘅 `sw.js` 同 `config.js` **byte 一樣**（`git diff HEAD origin/fix/quiz/back-to-entry -- sw.js js/core/config.js` 冇輸出）。所以第一條 merge + deploy 之後，第二條再 deploy 時：

- browser 嘅 SW update check 比較 `sw.js` + importScripts 嘅 `config.js` → 冇變 → 唔 install 新 SW
- 已裝 PWA / 開過網站嘅用戶繼續由 `lifeuk-v2.1.1` cache 讀第一條 branch 嘅 shell，第二條 branch 嘅改動（例如 CUI-0039 prune、或者 back-to-entry 嘅返回路由）**一直收唔到**，直到下一次升版本
- 新用戶就攞到新檔 → 同一個版本號兩種行為，bug report 對唔到

同 W-070（v2.0.3 撞）/ W-073（back-to-entry 2.0.3）同一類問題。
