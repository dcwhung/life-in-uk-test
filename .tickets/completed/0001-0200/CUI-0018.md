## 問題描述

`origin/main` @ `456f973`（PR #59 `0bbef98`「replace app icon…, APP_VERSION 1.0.1」+ PR #60）將 `js/core/config.js` 嘅 `APP_VERSION` 改咗做 `'1.0.1'`，但 `tests/plan-test.js`（PR1 加嘅，main 上面喺第 696 行）仲係咁寫：

```js
assert(g('APP_VERSION') === '1.0.0', 'APP_VERSION stays 1.0.0 in a middle PR (G19)');
```

呢句 assert 嘅原意（G19）係「溫習計劃中間嗰幾個 PR 唔好 bump 版本」，唔係要個版本永遠係 1.0.0。PR #59 係一個無關嘅 icon PR，佢 bump 版本係啱嘅。

## 預期結果

`plan-test` 喺 main 上面 pass；G19 嘅意思（計劃 PR 唔 bump 版本）仍然有 guard 守住。

## 實際結果

`plan-test` 喺 `origin/main` 同 PR2+main merge 完個 tree 上面都 fail；`run-all.sh` 會有 1 套紅。

## 建議修正

- 唔好寫死個版本號。可以改做同計劃 PR 開始前嘅 baseline 比較：例如 `PLAN_BASE_VERSION` 常數，PR 寫入 main 時跟住更新；或者直接刪咗呢句，喺 PR checklist 度講明 G19。
- 最好喺 PR2 rebase 上 main 嗰陣一齊改（PR2 本身冇整壞任何嘢）。
