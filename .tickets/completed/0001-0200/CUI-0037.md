## 問題描述

Home → Practice 模式「我的溫習 / My review」有兩粒 tile 掣（`<button class="my-tile">`）：

| 掣 | icon | 來源 |
|---|---|---|
| 錯題 / Wrong answers（`#tileWrong`，`data-action="startWrongReview"`） | 「✗」（U+2717，text glyph，紅色） | `js/screens/home.js:161` `renderReviewTile('tileWrong', wrongN, '✗', …)` |
| 已標記 / Flagged（`#tileFlagged`） | 書籤 SVG（`bookmarkSvg('rv-flag-tile')`） | `js/screens/home.js:162` |

HANDOFF「掣 icon 規則」：掣上面做 icon 嘅符號一律用 `icons.js` SVG line icon；「唔算掣 icon（保留）」清單有狀態字「✓ Correct / ✗ Wrong」（答題判定），但冇呢個 tile icon。同一行兩粒 tile 一粒 SVG 一粒 glyph，亦唔一致。v1.6.1 QA 冇見到係因為嗰次 Home 冇錯題（tile 收埋）；`control-icons-test` 都冇開錯題 tile。

## 重現步驟

1. Practice 卷答錯一題（或者記憶法試題答錯）
2. 返 Home → Practice 模式 →「我的溫習」
3. 錯題 tile 左上角係紅色「✗」字；旁邊旗標 tile 係 SVG 書籤

自動：`node .proj-docs/qa/scripts/2026-10-13_qa-v203.js F`（`F1 … Home "Wrong answers" tile mark is a line icon` FAIL，19 個 config 全部一樣：390 / 320 / 1024–1440）；截圖 `.proj-docs/qa/screenshots/v203/F1-home-wrong-tile-390-en.png`。
