## 預期結果

列印（有冇背景圖形都好）頁底係 `--bg`（或白），同 efa2af2 一樣；navy 只喺 header。

## 根源

`html { background: var(--navy) }` 喺 print media 都生效；分頁時 canvas 喺 body 以外嘅位置露出。

## 建議修正

```css
@media print { html { background: var(--bg); } }
```

（或者 `background: none`）。QA probe（scratch 注入，冇改 repo）：Home / 溫習 / 結果 × 邊距 0 / 1cm 最後一頁 navy 回到 0–0.8%，同 efa2af2 一樣。建議 `tests/overscroll-test.js` 加一個 `emulateMedia({ media: 'print' })` 讀 html computed background ≠ navy（或 `pg.pdf({ printBackground: true })` 最後一頁抽樣）。
