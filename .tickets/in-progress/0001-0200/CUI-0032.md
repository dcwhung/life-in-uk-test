## 修正（2026-10-12，branch `claude/beautiful-cerf-makp0n`，3d28b19；用戶決定唔齊頂，改為「細字斷行就縮細到一行」）

- `js/screens/planGoal.js` `fitPlanLevels()`（`planGoalRefit` 入面，render 尾／resize／轉語言／字體大小都會行）：先喺原本 size 決定 stacked（同之前一樣），三張並排時如果任何 `.plan-level-sub` 斷行，用 `fitSteps(..., { anyWidth: true })` 逐級加 `is-sub-tight` → `is-sub-tighter`；到下限仍然斷行就還原原本 size（維持換行）
- `css/screens/plan.css`：`.plan-levels:not(.is-stacked).is-sub-tight .plan-level-sub` = `(--fs-2xs + --fs-3xs) / 2`，`.is-sub-tighter` = `--fs-3xs`（下限）；三張同一個 class 喺 grid 上，size 一致；stacked 唔郁
- 1024 EN 一般字：12px → 11.4px，三張一行；中文 1024：唔縮（12px）；1140 EN 大字：14.4 → 13.8px；1024 EN 大字：下限 13.2px 都放唔落 → 維持 14.4px 換行（呢個情況 icon 仍會唔齊，屬用戶接受嘅「縮唔到就換行」）
- < 1024px：手機 sub 只准一行（斷行即 stacked），所以並排時冇斷行，唔會縮；390／600／1023 sub size 不變
- `tests/desktop-plan-test.js` `checkLevelSubs`：上述 5 個 case + resize 1280→1024→1280、轉中文、轉大字、< 1024 不變。Red：HEAD → FAIL（1024 EN 1 / 1 / 2 行）
