## 問題描述

`.header-inner` 同 `main` 都係 `max-width: var(--content-max-w)`（1280px）置中，但 `main` 自己有左右 padding（`--space-8` = 19.2px），header 嘅 padding 喺 `header` 外層。所以 viewport ≥ ~1328px 之後，logo／⚙ 比下面嘅卡片闊出 19.2px；1280 或以下就係 logo 入 4.8px（同手機一樣）。即係 1300px 左右會「跳」一次，對齊關係反轉。

| viewport | logo 左 | 卡左 | 差 |
|---|---|---|---|
| 1024 / 1280 | 24 | 19.2 | −4.8 |
| 1300 | 24 | 29.2 | +5.2 |
| 1366 | 43 | 62.2 | +19.2 |
| 1440 | 80 | 99.2 | +19.2 |
| 1920 | 320 | 339.2 | +19.2 |

## 重現步驟

1. 開 app，viewport 1920 × 1080（或 1440 × 900）。
2. 比較 header logo 左邊同 Home 計劃卡左邊；⚙ 右邊同卡右邊。

## 預期結果

「內容（header 內容 + main）最闊 1280px」：logo／⚙ 同下面內容邊一致（或者同 ≤ 1280 時一樣嘅細微差），唔會因闊度跳位。

## 實際結果

≥ 1328px：header 內容比 main 內容每邊闊 19.2px。

## 修正（2026-10-12，branch `claude/beautiful-cerf-makp0n`，f62041c；用戶揀「Header 同 main 左右對齊」）

- `css/base/layout.css`：≥ 1024px `header { padding-inline: 0 }`、`.header-inner { padding-inline: var(--space-8) }`，即 header 內容盒同 `main` 一樣：最闊 1280px 置中、入面同一個 inline padding（19.2px）。< 1024px 冇改（header 照用 20px padding、780px column）
- `css/components/popover.css`：desktop ⓘ／⚙ popover 嘅 `--info-pop-side` 跟住新嘅 header 內容邊（`max(--space-8, 50% − 640px + --space-8)`）
- 結果：logo 左 == 卡左、⚙ 右 == main 內容右：1024 19.2／1004.8、1280 19.2／1260.8、1328 43.2／1284.8、1440 99.2／1340.8、1920 339.2／1580.8，唔再喺 ~1300px 跳位（1024–1280 logo 由 24 → 19.2，同卡對齊）
- `tests/desktop-base-test.js`：新 `checkHeaderAlign`（1024／1280／1328／1440／1920，±0.5px；1023／390 logo／⚙ 位置同之前一樣）；`checkHeader` header 內容盒改為同 main 一樣闊。`tests/desktop-overlays-test.js` 量 header 內容盒（扣 padding）。Red：HEAD CSS → FAIL（1024 header content 976px）
