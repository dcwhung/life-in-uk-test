# CUI-0038 Desktop 矮畫面：撳 Translate／答題觸發 `.quiz-main.is-compact`，題號行 margin 收窄令題目字郁約 21.6px

**類型**：Layout 穩定性（desktop ≥ 1024，fitQuiz 收窄步驟）
**優先級**：🟢 Low（唔 block release：base v2.0.4 已經一樣，唔係 v2.0.5 regression；只係矮 desktop 畫面翻譯開時出現）

## 問題描述

Desktop（≥ 1024）題目欄由 `fitQuiz()`（`js/screens/quiz.js` 約 :558）逐步收窄：① 選項行跟內容（`.options.is-tight`）→ ② `.quiz-main.is-compact`（較窄 padding／gap）→ ③ 欄先捲。

`css/screens/quiz.css` 約 :253：

```css
.quiz-main.is-compact .q-num { margin-bottom: var(--space-3); }
```

1024×600／1024×768 翻譯開，未答題時欄夠位（冇 `is-compact`）；撳 Translate（題目下面多咗粵語翻譯）或者答題（多咗答案內容）之後內容變高，`fitQuiz` 加上 `is-compact`：

- `.q-num` margin-bottom 由 12px 變 7.2px（desktop scale 下嘅 `--space-3`）
- 同時 `.q-card` padding-top 收窄
- 結果 `#qText` 嘅絕對位置（viewport 座標）郁約 21.6px

v2.0.5 `qnum-row-test` 量嘅係「`#qText` 相對題號行頂、減去題號行 margin」嘅 offset（只守題號行自己嘅高度），所以呢個由 compact 引起嘅郁動唔喺佢範圍。

## 重現步驟

1. 視窗 1024×600（或 1024×768），英文或中文，翻譯開，Practice → Exam 1
2. 記低題目字（`#qText`）位置
3. 撳 Translate，或者揀答案
4. `#qText` 向上郁約 21.6px；`.quiz-main` 多咗 `is-compact`；`getComputedStyle(.q-num).marginBottom` 12px → 7.2px

base v2.0.4（v2.0.5 題號行改動之前）結果一樣。

## 預期結果

答題前後、撳 Translate 前後，題目字唔郁（同 v2.0.5 題號行目標一致：「答題時題目字唔郁」）。

## 建議方向（揀一）

- (a) 題號行 margin 同 card 頂 padding 唔參與 compact：只收窄題目字以下嘅間距（翻譯、選項 gap、選項 padding），題目字以上嘅位置固定。
- (b) Render 時預先用「答題後」嘅 compact 狀態量：如果答題後（或撳 Translate 後）會需要 `is-compact`，一開始就用，狀態之間唔再切換（類似 `fitQuestionCounter` 逐個狀態量嘅做法）。

## 測試建議

`desktop-quiz-test` 或 `desktop-short-test`：1024×600／1024×768 × EN／中 × 翻譯開，逐題量 `#qText.getBoundingClientRect().top` 喺未答、撳 Translate、答題後三個狀態，差 ≤ 0.5px。
