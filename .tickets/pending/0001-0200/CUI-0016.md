## 問題描述

錯題 review（`WRONG_EXAM`，Practice）答啱嘅題目會 `clearWrong`。如果一輪入面全部答啱，`wrongList` 變空。Result 頁「重做」→ `retryExam()` → `startExam('wrong')` → `poolFor` 回空陣列 → `state.questions = []`，`renderQuizHeader` 讀 `q.d` 拋 `TypeError: Cannot read properties of undefined (reading 'd')`。Quiz screen 已經 active，但 DOM 冇重畫，顯示嘅係上一輪最後一題（題號點全綠、答案已揀、答案框開咗）。

Flagged review（`FLAGGED_EXAM`）中途取消晒書籤都會有同樣情況。

## 重現步驟

1. `lifeuk.wrongList` 有 N 題
2. Home › 錯題 → 全部答啱 → Finish → Result
3. 撳「重做」

## 預期結果

錯題已經清晒時 Result 頁唔顯示「重做」（只留返主頁）；任何入口開空 set 都唔會進入 Quiz（返 Home），冇 page error。

## 實際結果

Page error + 畫面停喺上一輪最後一題嘅舊狀態。

## 環境

- Linux Chromium（Playwright，390px，touch）；v0.67 `d4fc661`
