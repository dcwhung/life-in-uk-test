## 問題描述

v1.4.3 將 `html` 背景改做 `var(--navy)`（W-063，bounce 時見到嘅 canvas）。螢幕上 body `min-height: 100vh` 蓋住成個 viewport，所以冇事；但係列印係分頁，body 只係延伸到內容完結，**最後一頁內容以下嘅位置露出 html 背景 = navy**（只限開「背景圖形」/ `printBackground: true`）。

| 畫面（390px，A4） | 邊距 | efa2af2（改之前）最後一頁 navy % | 5ea5024 最後一頁 navy % |
|---|---|---|---|
| Home | 0 | 5.8（1 頁，只係 header） | 5.8 |
| Home | 1cm | 0 | **63.9** |
| 溫習 | 0 | 0 | **85.5** |
| 溫習 | 1cm | 0 | **71.6** |
| 模擬考試結果（13–14 頁） | 0 | 0.8 | **9.6** |
| 模擬考試結果 | 1cm | 0.9 | **2.9** |

中間頁（內容滿頁）同邊距位置冇 navy；冇開背景圖形（預設）全部 ≤ 0.2%。

## 重現步驟

1. Chrome 開 `index.html`（390 × 844 或任何闊度），去「溫習」
2. 列印 → 更多設定 → 勾「背景圖形」
3. 預覽第 2 頁：內容完結之後成頁深藍

自動：`node .proj-docs/qa/scripts/2026-10-12_qa-v143-overscroll.js`（最後 print PDF 段，`study printBackground=true` page 2 = 85.5%）。截圖：`.proj-docs/qa/screenshots/v143/print-study-bg-page2-390.png`

## 預期結果

列印（有冇背景圖形都好）頁底係 `--bg`（或白），同 efa2af2 一樣；navy 只喺 header。

## 根源

`html { background: var(--navy) }` 喺 print media 都生效；分頁時 canvas 喺 body 以外嘅位置露出。

## 建議修正

```css
@media print { html { background: var(--bg); } }
```

（或者 `background: none`）。QA probe（scratch 注入，冇改 repo）：Home / 溫習 / 結果 × 邊距 0 / 1cm 最後一頁 navy 回到 0–0.8%，同 efa2af2 一樣。建議 `tests/overscroll-test.js` 加一個 `emulateMedia({ media: 'print' })` 讀 html computed background ≠ navy（或 `pg.pdf({ printBackground: true })` 最後一頁抽樣）。
