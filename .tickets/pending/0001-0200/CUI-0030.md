## 問題描述

Desktop（≥ 1024px）Home 計劃卡倒數時間軸，喺有 color-mix() 嘅 browser（Chrome / Safari 16.2+，即大部份用戶），已過／今日嘅 learn 格（實色）顏色係 `color-mix(in srgb, var(--navy-light) 45%, var(--person-bg))` ≈ rgb(147,161,198)，休息日格係 `--text-inverse-faint`（白 45%）疊喺 navy-light 上 ≈ rgb(140,150,185)。兩者對比只有 **1.14 : 1**，肉眼幾乎分唔到邊日係休息日。

Design Origin `mockups/v2.0.0/desktop-home-plan.html`（A rev 7 + Ring + T）用 `--cd-learn: #8fa3ec`、`--cd-rest: rgba(255,255,255,0.3)`：learn rgb(143,163,236) vs rest rgb(109,121,166) = 1.75 : 1，休息日明顯係暗灰。grill「實作備忘」亦寫明「休息日灰」。

（W-380 嘅 fallback 路徑反而 OK：冇 color-mix 時 learn = --person-bg，對休息日 2.55 : 1。）

## 重現步驟

1. 1280 × 800（或 1024 × 768），EN，一般字。
2. 建一個 21 日計劃，休息日 = 星期日，今日 = Day 9（tests 用嘅 seed：`buildPlan({ dailyMins:120, restDays:[0], level:'none', examDate })`）。
3. 返 Home，睇計劃卡時間軸「Today」左邊嘅格。

## 預期結果

休息日（灰）同已過 learn 日（淺藍）一眼分得出，顏色接近 mockup（#8fa3ec 淺藍、白 30% 灰）。

## 實際結果

learn 格係偏灰嘅藍 rgb(147,161,198)，休息日 rgb(140,150,185)，兩者幾乎一樣；learn 色亦比 mockup 灰／暗淡。
