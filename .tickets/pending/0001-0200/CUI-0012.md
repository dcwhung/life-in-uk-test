## 問題描述

`.rdots` / `.nav-dots` 都係 `grid-template-columns: repeat(12, 1fr)`。`1fr` 嘅最細值係 `auto`（min-content），所以每欄起碼要有圓點入面數字（"24"，10.5px / 800）+ border 咁闊。S-034 之後 `<button>` 用 body font，喺測試環境（Linux Chromium）"24" 由 11.69px 變 13.77px，所以：

- **結果頁 `#resultDots`**（`.rdot` border 2px）：每欄最少 16 → 17.97px，12 欄 + 11 × 6px gap = 281.6px（v0.63：258px）
- **Quiz `#navDots`**（`.dot` border 1.5px）：每欄 14.84 → 15.97px

窄過大約 362px 嘅 viewport，圓點 grid 闊過 `.result-card` 嘅 content box，向右凸出；320–335px 直情凸出白色卡片邊，320px 頁面多咗 2px 橫向 scroll。390px 或以上冇影響。

量度（圓點最右邊 − 卡 content box 右邊 / − 卡外框右邊；`doc` = 頁面 scrollWidth − viewport）：

| Viewport | v0.63 `984d374` result dots | v0.64 `3952f3c` result dots | v0.64 quiz nav dots |
|---|---|---|---|
| 320 | content +18 / card −6 / doc 0 | **content +41.6 / card +17.6 / doc +2** | content +13.6 / card −8.4 |
| 325 | +13 / −11 / 0 | **+36.6 / +12.6** / 0 | +8.6 / −13.4 |
| 330 | +8 / −16 / 0 | **+31.6 / +7.6** / 0 | +3.6 / −18.4 |
| 335 | +3 / −21 / 0 | **+26.6 / +2.6** / 0 | 0 |
| 340–360 | 0 | +21.6 → +1.6（喺卡 padding 入面） | 0 |
| ≥ 365 | 0 | 0 | 0 |

v0.63 喺 320–335px 已經超出 content box（喺卡 padding 入面，睇唔出），S-034 令佢凸出卡邊。

## 建議修正

- 方案 A（推薦）：`grid-template-columns: repeat(12, minmax(0, 1fr))`（`.rdots`、`.nav-dots`），欄闊唔再受數字闊度影響；再喺 `@media (max-width: 360px)` 細少少 `.rdot` / `.dot` 字（例如 10.5 → 9.5px），令 "24" 喺細圓點入面唔會頂住 border。Trade-off：320px 圓點會細過 v0.63 少少（約 14.5px）。
- 方案 B：`@media (max-width: 360px)` 將 gap 6 → 3px（12 × 17.97 + 33 = 248.6px，仍然闊過 320px 嘅 240px content box），要配合字細先夠；改動細但要兩樣一齊改。
- 方案 C：接受（320px 裝置少），喺 HANDOFF S-034 段記低。
- 測試：`practicedots-test` / `examresult-test` 加 320px：`#resultDots` / `#navDots` 最右圓點 ≤ 卡 content box 右邊，`document.documentElement.scrollWidth === innerWidth`。
