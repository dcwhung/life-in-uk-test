## 問題描述

CUI-0039 / S-262 令 `planTaskQids()` 過濾過時 qid（`isValidQuestionKey`），所以 review / practice / drill task 嘅進度、開 task、做題都只用真題目 —— QA P3 驗證咗 practice task 加 `99.99` / `1.999` 之後 day 畫面數 9（存咗 11）、開 task 只問真題、冇 page error。

但仲有兩個地方直接讀 `task.qids`，冇經 `planTaskQids()`：

1. `js/domain/planProgress.js` `planLearnContentDone()`（約 199 行）：
   `const qids = tasks.filter(t => t.type === PLAN_TASK.practice).flatMap(t => t.qids || []);` → `qids.every(k => done.qids.has(k))`。
   過時 qid 永遠唔會喺 `done.qids`（答唔到）→ **Learn 階段永遠唔算完成** → `planPhaseDone(…, learn)` false → 計劃表（`planSchedule.js` G43）Learn 階段永遠唔會轉綠 ✓。
2. `js/screens/planSchedule.js` `case PLAN_TASK.practice: … n: task.qids.length`（約 238 行）：task 標題「Practise Ch 1 …: 11 Qs」數埋過時 qid，但 day 畫面 status 數 9（code read，未逐格量）。

幾時會出現：已存 `lifeuk.studyPlan` 入面 learn 階段 practice task 喺 build 時已經 materialize（`PLAN_CHAPTER_QIDS`），之後題庫更新刪題 / 重排 index。`plan.js` `planValidTask` 只檢查 qid 係字串（`planValidList(t.qids, k => typeof k === 'string')`），所以唔會因此重建計劃。
