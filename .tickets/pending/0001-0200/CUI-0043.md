## 問題描述

v2.2.0 用戶定稿規則「年份數字後面跟『年』、中間一個空格」（`45 年 Attlee`）同「Northern Ireland 寫 `N. Ireland`」，`data/memo.js` 用普通空格（U+0020）。`.memo-hook span` 係 `white-space: pre-line`，普通空格係斷行位，所以 hook 框窄嘅時候會喺 token 中間斷：

- `1928` 喺行尾、`年` 喺下一行開頭（例：320×568 zh-HK 大字 `vote`「十年後 1928 / 年先同男人一樣 21」）
- `N.` 喺行尾、`Ireland` 喺下一行（320 大字 `nation-symbols` 兩次、`devolved`）
- `AD` / `43`、`AD` / `410`（390 `early-britain`）

QA 逐個 token 量（Range rects；token = `N. Ireland`、`\d+(–\d+)? 年`、`\d+ BC`、`AD \d+`）：

| viewport / UI / 字 | 斷開 token 數 |
|---|---|
| 320 en small / large | 5 / 8 |
| 320 zh-HK small / large | 4 / 7 |
| 390 en small / large | 4 / 3 |
| 390 zh-HK small / large | 5 / 5 |
| 1280 en small / large | 2 / 2 |
| 1280 zh-HK small / large | 0 / 0 |

（日期 `25/1` 等冇斷。）
