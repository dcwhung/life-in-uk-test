## 3. 觀察（非缺陷）

- **Resize 後即刻量會差 4px**：Playwright `setViewportSize` resolve 時 `resize` event 未 dispatch（下一 frame 先到），所以即刻量箭咀會用舊 `--info-arrow-x`（例如 199px vs 195px，相差 = header padding 20px 同 popover gutter 16px 之差）。等 event 之後（300ms 或下一個 evaluate）全部 0.16px。真用戶冇影響。`tests/info-test.js` 喺 resize 後先做一次 `$eval` 再量箭咀，所以而家穩定；如果將來刪咗中間嗰個 `$eval`，可能變 flaky — 建議 assert 前加 `waitForFunction`。
- **撳語言掣會關 popover**：語言掣喺 popover 外面，outside-click 關 popover 係原有設計；再開時 `toggleInfo` 會 `renderPlanSettings()`，pill / note 即係新語言。關住嘅 popover 入面嘅 pill / note 未更新，但用戶睇唔到。
- S-131（「408 Qs」screen reader 讀法）：QA 後用戶要求修，3c4dc6b 加 `role="img"` + `aria-label`（info-test 守住）。
