## Section A：Study timeline（年份 cap-trim、dot 置中、6px gap）

用**像素**量度，冇用 suite 嗰套 box model 計法：每個 `.tl-item` 用 2× 截年份欄 + dot，搵年份文字嘅 ink 上下界同 dot 嘅 ink 上下界，比較兩個中點（82 個年份全部量到，包括紅色戰爭年份）。

| | v0.69 | v0.70 |
|---|---|---|
| 平均偏差（320 / 390 / 900） | 3.9 / 4.0 / 3.5 px | **0.05 / 0.09 / 0.53 px** |
| 最大偏差 | 4.0 / 4.25 / 5.25 px | 1.25 / 1.75 / 1.75 px |
| 兩行年份（`c. 4000 BC`、`18th–19th century` 等） | dot 對住第一行（+3 至 +5px） | dot 喺兩行中間（−0.5 至 +1.75px） |

- 剩低嗰 ≤ 1.75px 全部係有細楷 descender / ascender 嘅年份（`century` 嘅 y、`Iron Age` 嘅 g、`th`）。cap-trim 係按大楷 / 數字計，所以 ink 會稍為偏低；純數字年份係 0 – 0.5px（2× 下即係 1 個 device pixel）。符合設計
- 6px gap：v0.69 `9th–10th century` 嘅文字貼住 dot 外圈（見截圖 02），v0.70 有空位。因為 gap，`c. 4000 BC` / `c. 3000 BC` / `post-1945` 喺 320 / 390 變咗兩行，dot 照樣喺中間
