## 5. 觀察（唔係 bug，冇 ticket）

1. **學習日冇錯題時 ring 一開始係 1%，唔係 0%**：G9「錯題簿空 = 清錯題自動完成」，所以 learn day 嘅 review task 算 1 / 1 done → 今日 % = 1（例如新計劃 Day 1、Day 4 冇 log）。ring 會畫一點 h1 短 arc（round cap）；0% 隱藏 arc 只會喺今日有錯題要清、或者 drill / mock 日先見到。今日任務畫面嘅大 ring 一樣（pre-existing 計法，v1.5.0 冇改）。如果產品想「未做任何嘢 = 0%」，要改 `planDayCompletion` 唔計空 review —— 屬 product 決定，唔係今次 scope。
2. 320 大字 en 100%（「View today's tasks」較長）同 zh-HK 已完結（三粒掣），掣會 wrap 去第二行，兩行都右靠；冇出界 / 截字。同 variant B 設計方向一致。
3. 1100px 卡橫跨成個 content，ring 喺最右、label / next 喺最左，中間大片空位（`card-mid-en-1100-small.png`）；功能 OK，baseline 只定義 390。
4. 建議補測（QA 唔 commit test，交 developer 跟進）：`plan-day-test` 嘅「掣右靠」只 assert active 狀態嘅 `justifyContent`；可以加考試日 / 已完結 / 未開始最後一粒掣右邊 = 卡 content 邊；0% 狀態而家只用 helper synthetic，可以加一個 seed wrong list 嘅真 0% 卡。
