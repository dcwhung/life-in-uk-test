## 1. CUI-0008 — install prompt

| Case | 結果 |
|---|---|
| desktop（fine pointer）：event `preventDefault`，banner 唔出；`promptInstall()` 仍 call 到 `prompt()` | ✅ |
| mobile coarse pointer 真 match（冇 override） | ✅ |
| accepted（真 tap Install）→ `prompt()` 1 次、banner 收、`lifeuk.installDismissed` = `null` | ✅ |
| dismissed（真 tap）→ banner 收、key `null`、`deferredPrompt === null` | ✅ |
| dismissed 之後下一個 `beforeinstallprompt` → banner 再出；reload + event → 再出（取消 ≠ ✕） | ✅ |
| 雙擊：兩下 tap / `dblclick` / focus + 兩下 Enter / `Promise.all` ×3 → `prompt()` 都係 1 次、banner 收 | ✅ |
| `prompt()` reject `InvalidStateError` + `userChoice` 永不 settle → `promptInstall()` 1.5s 內 resolve、banner 收、key `null`（直接 call + 真 tap 兩條路） | ✅ |
| QA edge：`prompt()` **同步 throw** `NotAllowedError` → 喺 `try` 入面（array literal 建構時 throw）被 catch，resolve、banner 收 | ✅ |
| QA edge：`prompt()` resolve 但 `userChoice` 50ms 後 reject → resolve、banner 收、冇 unhandled rejection | ✅ |
| QA edge：未有 event 時 `promptInstall()` → no-op resolve | ✅ |
| `appinstalled` → banner 收、key 唔寫；再 dispatch 一次 → no-op | ✅ |
| ✕（tap）→ 寫 `"true"`；reload + event → banner 唔出；之後 `promptInstall()` 唔 throw | ✅ |
| 全部 mobile case：0 pageerror、0 console error | ✅ |

觀察（非 bug，同 review S-027）：`appinstalled` 之後 `deferredPrompt` 仍然指住舊 event（`deferredPrompt !== null` = true）。banner `display:none`，Install 掣唔可撳亦唔可 focus，UI 冇路觸發；跟 review 排下一個 PR。
