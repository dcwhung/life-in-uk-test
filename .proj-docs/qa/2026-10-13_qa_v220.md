## 7. 失敗 / 問題詳情

### F-1 🟢 普通空格令年份 /「年」、「N.」/「Ireland」、「AD」/ 年份斷開兩行 → **CUI-0044**

- **位置**：`data/memo.js` hook 用 U+0020（用戶定稿規則「45 年」「N. Ireland」）；`css/screens/memo.css` `.memo-hook span { white-space: pre-line }` → 空格係斷行位
- **預期**：「1928 年」「N. Ireland」「AD 43」唔拆開
- **實際**（`2026-10-13_qa-v220-token-split.js`）：斷開 token 數 320：en 5 / 8、zh-HK 4 / 7（細 / 大）；390：en 4 / 3、zh-HK 5 / 5；1280：en 2 / 2、zh-HK 0 / 0。例：320 zh-HK 大字 `vote`「十年後 1928」行尾、「年先同男人一樣 21。」下一行（`CUI-0044-320-zh-HK-large-vote-year-split.png`）；`nation-symbols`「N.」/「Ireland」（`H-320-zh-HK-large-nation-symbols.png`）
- **根源**：定稿加咗空格做分隔，但冇用 non-breaking space
- **建議**：render 時（`memoHookHtml`）將呢幾類 token 入面嘅空格換 U+00A0，唔郁定稿 data（詳見 ticket）；或者用戶同意後 data 改 U+00A0
- **影響**：只係排版；內容全對、冇 overflow / 裁切。唔 block

### 記錄（唔開 ticket）
