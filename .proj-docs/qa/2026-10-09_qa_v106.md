## 5. 主動補測（建議加入 `tests/modal-test.js`，QA 唔 commit）

QA 喺探索 script 跑過以下 edge case，全部 pass；建議由 developer 加入 suite：

1. **紅 → 正常唔殘留**：開紅框 → 關 → 開 Submit，斷言冇 `.danger`、title 唔係紅（`classList.toggle(…, false)` 回歸保護）。
2. **Cancel / Esc / backdrop 唔改資料**：seed 資料後逐個方法關閉紅框，斷言 localStorage 冇變。
3. **Enter 喺剛開嘅紅框唔會清資料**：鍵盤開 reset 之後即 Enter，資料仍在。
4. **Confirm 真係清資料，只清對應部分**：practice reset 保留 completed + plan；plan reset 保留 practice 記錄同 switch。
5. **鍵盤 vs 滑鼠 focus**：滑鼠開時 Cancel 冇 tint；鍵盤開時有 tint + inset。現有 W-043 assert 係 `!fv || inset`，fv=false 時冇驗任何嘢；建議分開兩個 case 強制驗。
6. **量 OK focus ring 要等 transition**：`.nav-btn { transition: all 0.15s }` 令 outline-width 由 0 漸變，即刻量會得 `0px`（QA 第一次跑誤報 32 次，等 400ms 之後全部正確）。日後加 assert 要 `waitForTimeout(≥200)`。
