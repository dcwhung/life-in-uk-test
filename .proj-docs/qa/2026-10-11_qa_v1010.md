### 4.2 S-165 實測（Part 3）

`.note-cell-sub` 11px，200px 闊格入面一條 4 行嘅「• 」備注：

| 字型 | 「• 」闊度 | 換行後同第一行文字差 |

| App 預設 stack（呢度 resolve 到 Inter） | 0.844em | +0.61px |
| Inter | 0.844em | +0.61px |
| DejaVu Sans | 0.908em | −0.09px |
| WenQuanYi Zen Hei（CJK） | 0.649em | **+2.75px** |
| Unifont | 1.000em | −1.11px |

判斷：**🟢 Suggestion，唔 block，唔開 ticket**。理由：(1) 實際 data 喺 390px 0 個 bullet 備注換行，320px 只係 Study 3 個換行，所以絕大部份畫面根本冇第二行；(2) iOS / Android 「•」通常由 Latin 字型（SF / Roboto）出，同 Inter 接近（< 1px）；只有「•」落到 CJK 字型先會差約 3px（reviewer Noto Sans CJK HK 3.3px，同我 WenQuanYi 2.75px 吻合）；(3) 純視覺，唔影響閱讀。同意 reviewer 方案 A（固定闊度 mark span）下個 patch 做。
