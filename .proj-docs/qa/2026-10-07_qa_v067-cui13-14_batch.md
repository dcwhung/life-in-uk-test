### 1. v065 script `langAttrs`

**原 script（冇改）**，`QA_ONLY=glossary,langAttrs` 喺 HEAD 仍然印 6 條 note：

```
note: lang gap quiz: #ansNote > strong → … should be zh-HK (0/1)
note: lang gap result: .rv-your → … should be en (23/23)
note: lang gap study chapters: #studyContent .study-group-title → … should be en (0/1)
note: lang gap study timeline: #studyContent .tl-year → … should be en (0/82)
note: lang gap study timeline: #studyContent .tag.person → … should be en (0/32)
note: lang gap home chapter grid: #chapterGrid .ch-name → … should be en (0/5)
```

同 base `a3fbe00` 比（1/1、23/23、1/1、82/82、32/32、5/5），除咗 `.rv-your` 之外全部由「全部漏」變「0 漏」。仍然有 note 印出係 **script oracle 嘅兩個問題**，唔係產品問題：

1. `gaps()` 用 `res.filter(r => r.n)`，冇 filter `untagged = 0`，所以 0 漏都照印（line 694）。
2. `.rv-your` 量嘅係成個容器。S-047 方案 A（ticket 表都寫「答案部分 `lang="en"`」）係 label「你的答案：」跟 UI 語言、答案包 `<span lang="en">`，所以容器本身**按設計**承繼 `zh-HK`。正確 selector 係 `.rv-your > span`。

將 script 複製去 scratchpad，**只改呢兩處**（`r.n && r.untagged`、`.rv-your > span`）再跑 `QA_ONLY=langAttrs` → **12 / 12 pass，0 條 `lang gap`**，`W-014 remaining gaps: ` 係空。原 v065 script 冇改（係 v0.65 嘅 QA 記錄）；建議之後再用呢份 script 時套用呢兩處（見「測試建議」）。
