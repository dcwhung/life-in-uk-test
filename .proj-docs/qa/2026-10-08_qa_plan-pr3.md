## 失敗測試詳情

### CUI-0019 — date field focus 時第一下撳 chip / 程度卡被食咗（🟡）

- **位置**：`js/screens/planGoal.js` `planCommitExamDate()`（`data-blur-action`）→ `renderPlanGoal()` → `renderPlanDays` / `renderPlanRest` / `renderPlanLevels`（`innerHTML` 重建）
- **預期**：focus 喺 date field 時撳「2 weeks」→ 14 日
- **實際**：draft 唔變、`activeElement = BODY`；要撳第二下。三個 group 都中；手機用原生 picker 揀完日期，input 仍有 focus，所以「揀日期 → tap 休息日」嘅第一下一定冇效
- **根源**：mousedown 令 date field `focusout` → commit 即刻重建 chip → mouseup 落喺新 element → `click` 派去共同 ancestor（冇 `data-action`）。Review Round 2 估計「chip 會覆蓋」，但冇用真 click 驗
- **建議**：commit 冇改 draft 時唔 re-render（只寫返 input value）；或者 chip / 卡改原位更新 class + `aria-pressed`。加真 click test
