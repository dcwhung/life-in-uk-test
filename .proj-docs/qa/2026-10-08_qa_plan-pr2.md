## 觀察（唔係缺陷，冇開 ticket）

- **O-1**：PR2 rebase 上 main 之後，`APP_VERSION` 會變成 1.0.1（跟 main）。G19「中間 PR 唔 bump」照樣做到，因為 PR2 自己冇 bump；CUI-0018 修好之後就唔會有衝突。
- **O-2**：Exam mode 時間到自動交卷，一樣當模擬考 attempt 記錄（分數照計，合格與否由 G10 ≥ 18/24 判斷）。我認為呢個行為合理，因為真考試時間到都係交卷；G15 講嘅「計時中當離開、唔交卷」只適用於關開關。PR6b 做 UI 時，建議喺 plan 文件寫明「時間到 = 交卷」。
- **O-3**：直接 call `finishExam()` 第二次會多記一次 mock，但 UI 冇路徑做到：結果頁冇 Submit，confirm modal 撳一次就關。
- **O-4**：混合載入時，如果 `quiz.js` 係新版而 `planProgress.js` 係舊 cache（冇 `planSameQuestionKeys`），plan review session 答啱會 `ReferenceError`。但而家冇 UI 入口可以開 plan review session；SW 亦係一次過 `addAll` 成個 cache，正常升級唔會出現呢個組合。PR6a 開放入口時，有版本 bump 就會一齊更新。
- **O-5**：`retryExam()` 用 Home 嘅 `pendingMode`，plan 文件 §PR6b 已經列咗（plan mock 再考要用 `EXAM_MODE`），呢度唔重複。
