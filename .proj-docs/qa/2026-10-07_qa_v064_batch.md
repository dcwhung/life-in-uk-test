## 失敗測試詳情

### CUI-0012 — 320–360px：結果頁圓點（同 320–330px quiz 圓點）凸出卡片
- **位置**：`css/components/dots.css`（`.rdots` / `.nav-dots` `grid-template-columns: repeat(12, 1fr)`）× `css/base/layout.css:13`（S-034）
- **預期**：圓點留喺 `.result-card` 入面，320px 頁面冇橫向 scroll（v0.63：320px `scrollWidth` 320）
- **實際**：320px `scrollWidth` 322；`#resultDots` 第 12 欄（"12"、"24"）凸出卡片右邊 17.6px（320）→ 2.6px（335）；340–360px 仍然超出 content box（喺卡 padding 入面）；`#navDots` 320–330px 超出 content box 3.6–13.6px
- **錯誤訊息**：`FAIL: S-034 320 result: no new horizontal page overflow (doc 322, base 320)`；`FAIL: S-034 320 result: no control spills / is cut, none past the viewport ()`（`.rdot` right 321.6）
- **根源**：`1fr` = `minmax(auto, 1fr)`，每欄最少 = 圓點數字 min-content + border。"24"（10.5px / 800）喺 body font 13.77px（Arial 11.69px）→ `.rdot` 欄 16 → 17.97px，12 欄 + 66px gap = 281.6px（v0.63 258px）。v0.63 喺 320–335px 已經超出 content box（喺 padding 入面睇唔出）
- **建議**：`repeat(12, minmax(0, 1fr))` + `@media (max-width: 360px)` 圓點字細少少；詳見 ticket
- **截圖**：`2026-10-07_v064_cui0012_result-dots_320_head.png`、`…_320_base.png`
