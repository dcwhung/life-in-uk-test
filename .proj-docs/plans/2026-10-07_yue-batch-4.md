## 本批用到嘅語感規則（同 batch 1）

| 規則 | 例子 |
|---|---|
| 誰 → 邊個 | 《哈姆雷特》係誰寫的？ → 係邊個寫嘅？ |
| 哪 / 哪天 / 哪年 / 哪裏 / 哪些 → 邊 / 邊日 / 邊年 / 邊度 / 邊啲 | 節禮日係哪天慶祝？ → 喺邊日慶祝？；哪些故事 → 邊啲故事 |
| 的 → 嘅 | 公務員的角色 → 公務員嘅角色 |
| 在 / 位於 / 出生於 → 喺 / 喺 / 喺…出世 | 湖區國家公園位於哪裏？ → 喺邊度？；誰出生於… → 邊個喺…出世？ |
| 了 / 甚麼・有何 → 咗 / 咩 | 發生了甚麼事 → 發生咗咩事；有何重要性 → 有咩重要性 |
| 不 / 非 / 嗎 → 唔 / 唔係 / 係唔係・受唔受 | 不屬於 → 唔屬於；非歐盟機構 → 唔係歐盟機構；係英國一部分嗎？ → 係唔係英國嘅一部分？ |
| 和 / 與 / 並 / 為 → 同 / 同 / 去掉 / 幫 | 與英國有關 → 同英國有關；執行政府政策並保持政治中立 → 執行政府政策，保持政治中立；為政黨拉票 → 幫政黨拉票 |
| 為何 / 如何 / 多久 → 點解 / 點樣 / 幾耐 | 女性為何獲得投票權 → 點解女性…得到投票權；首相係如何產生的 → 係點樣產生嘅；打了多久 → 打咗幾耐 |
| 多少 → 幾多 | 有多少名議員 → 有幾多名議員 |
| 約 / 另有 / 後 / 時 → 大約 / 另外有 / 之後 / 嗰陣 | 約100萬人 → 大約100萬人；二戰後 → 二戰之後；加冕時 → 加冕嗰陣 |
| 書面動詞 → 口語動詞 | 獲得 → 得到；導致 → 令；賦予 → 俾；攜帶 → 帶；率領 → 帶領（同 X2）；又稱 → 又叫；至 → 到；給 → 俾；老年人 → 長者 |
