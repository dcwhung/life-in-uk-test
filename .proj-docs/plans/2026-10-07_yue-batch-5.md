## 本批用到嘅語感規則（同 batch 1）

| 規則 | 例子 |
|---|---|
| 誰 → 邊個 | 邱吉爾係誰？ → 邱吉爾係邊個？；1945年大選誰勝出？ → 1945年大選邊個贏？ |
| 哪 / 哪天 / 哪年 / 哪裏 / 哪些 / 哪時 → 邊 / 邊日 / 喺邊年 / 邊度 / 邊啲 / 幾時 | 柏林圍牆係哪年倒塌？ → 喺邊年倒塌？；莎士比亞在哪裏上學？ → 喺邊度讀書？；聯合國係哪時成立的？ → 係幾時成立嘅？ |
| 的 → 嘅 | 工會的角色 → 工會嘅角色 |
| 在 → 喺 | 在內戰失敗後 → 喺內戰失敗之後；在英格蘭推動 → 喺英格蘭推動 |
| 了 / 甚麼・有何 → 咗 / 咩 | 帶來了甚麼影響 → 帶來咗咩影響；有何重要性 → 有咩重要性 |
| 不 / 而非 → 唔 / 而唔係 | 不屬英國 → 唔屬於英國；不得徵稅 → 唔可以徵稅；而非成文法例 → 而唔係成文法例 |
| 和 / 與 / 並 → 同 / 同 / 「，」 | 安·博林和凱薩琳·霍華德 → 同；監督選舉並管理 → 監督選舉，管理 |
| 必須 → 一定要（規則 12） | 必須年滿21歲 → 一定要年滿21歲；必須保持政治中立 → 一定要保持政治中立 |
| 時 / 後 / 約 / 還有 → 嗰陣 / 之後 / 大約 / 仲有 | 首相辭職時 → 首相辭職嗰陣；二戰後 → 二戰之後；約5,000年前 → 大約5,000年前；還有盎格魯人 → 仲有盎格魯人 |
| 書面動詞 → 口語動詞 | 成為 → 變成・做咗；擊敗 → 打敗；如何 → 點樣；來到 → 嚟到；說 → 講；被稱為 → 叫做；賦予 → 俾；選擇 → 揀；均曾獲獎 → 都贏過奧斯卡；所作 → 寫嘅 |

結構調整：「亨利八世除宗教改革外還以甚麼著名？」→「亨利八世除咗宗教改革，仲因為咩而出名？」；「英格蘭哪時係共和國而非君主制？」→「英格蘭幾時係共和國，而唔係由君主統治？」；「1948年，Windrush（疾風號）號抵達」→「1948年，Windrush（疾風號）嚟到英國」（順手刪咗重複嘅「號」）。
