## 本批用到嘅語感規則（同 batch 1）

| 規則 | 例子 |
|---|---|
| 誰 → 邊個 | 1745年誰得…支持起兵？ → 1745年邊個得到…支持起兵？ |
| 哪 / 哪年 / 哪裏 → 邊 / 喺邊年 / 邊度 | 首都係哪裏？ → 嘅首都係邊度？ |
| 的 → 嘅 | 英格蘭流通的 → 嘅；打敗拿破崙的名將 → 嘅名將 |
| 在 / 位於 → 喺 | 位於哪個城市 → 喺邊個城市 |
| 了 / 甚麼・什麼 → 咗 / 咩・乜嘢 | 發生了什麼事 → 發生咗咩事 |
| 不 → 唔 | 不能拒絕 → 唔可以拒絕 |
| 和 / 與 / 共同 → 同 / 同 / 一齊 | 共同研發 → 一齊研發 |
| 才 → 先 | UK 才包括 → UK 先包括 |
| 為何 / 多久 / 多少 → 點解 / 幾耐 / 幾多 | 多久舉行一次 → 幾耐舉行一次 |
| 書面動詞 → 口語動詞 | 說服…參與 → 勸…參加；欲取回 → 想攞返；企圖 → 想；逃往 → 逃去；成為 → 做咗 |
