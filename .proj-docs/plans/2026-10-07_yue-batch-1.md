| 7 | 甚麼 / 了甚麼 | 乜嘢 / 咩 / 咗咩 | 發生了甚麼事 → 發生咗咩事 |
| 8 | 動詞 + 了（完成） | 動詞 + 咗 | 發明 → 發明咗；引入了 → 引入咗 |

| 10 | 給 | 俾 | 寫信給 → 寫信俾 |
| 11 | 和 / 及 / 或 / 並 | 同 / 同 / 或者 / 而且・仲 | 犯罪、警政及移民 → 罪案、警政同移民 |
| 12 | 須 / 必須 | 一定要 | 必須確保 → 一定要確保 |
| 13 | 才 / 時 | 先 / 嗰陣 | 投票時才用 → 投票嗰陣先會用 |

結構調整：生硬句子改為口語語序，例如「玫瑰戰爭係兩個哪些家族之爭？」→「玫瑰戰爭係邊兩個家族之間嘅戰爭？」；「陪審員的最低年齡係幾歲？」→「做陪審員最少要幾歲？」。
