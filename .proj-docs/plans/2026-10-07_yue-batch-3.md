## 本批用到嘅語感規則（同 batch 1）

| 規則 | 例子 |
|---|---|
| 誰 → 邊個 | 電話係誰發明的？ → 電話係邊個發明嘅？ |
| 哪 / 哪天 / 哪年 / 哪裏 / 哪時 → 邊 / 邊日 / 喺邊年 / 邊度 / 幾時 | 聖佐治日係哪天？ → 係邊日？；復活節係哪時舉行？ → 喺幾時舉行？ |
| 的 → 嘅 | 警察的職責 → 警察嘅職責 |
| 在 / 位於 / 出生於 → 喺 / 喺 / 喺…出世 | 出生於林肯郡的烏爾斯索普 → 喺林肯郡嘅烏爾斯索普出世 |
| 了 / 甚麼・什麼 → 咗 / 咩・乜嘢 | 牛頓發現了乜嘢 → 發現咗乜嘢；有甚麼重要性 → 有咩重要性 |
| 不 / 非 / 不可 → 唔 / 唔係 / 唔可以 | 不包括北愛爾蘭 → 唔包括；（非歐盟）→（唔係歐盟） |
| 給 → 俾 | 寫信給總警司 → 寫信俾總警司 |
| 和 / 與 / 或 / 並 → 同 / 同 / 或者 / 去掉 | 與歐盟係不同機構 → 同歐盟係唔同嘅機構；關閉…並沒收財產 → 關閉…，沒收佢哋嘅財產 |
| 才 / 時 → 先 / 嗰陣 | 哪年…才獲得投票權 → 喺邊年先有投票權；去世或辭職時 → 去世或者辭職嗰陣 |
| 約 / 共 / 現稱 / 現時 / 後 → 大約 / 一共 / 而家叫做 / 而家 / 之後 | 約20位 → 大約20位；大火後重建 → 大火之後重建 |
| 多少 → 幾多 | 有多少名議員 → 有幾多名議員 |
| 書面動詞 → 口語動詞 | 建造 → 起；成為 → 做 / 變成；賦予 → 俾；企圖 → 想；坐了20年牢 → 坐咗20年監；倡導 → 爭取；駕駛 → 揸 |
