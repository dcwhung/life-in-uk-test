## 🟡 Warnings

### W-013 — zh-HK locale 冇載入時，pill 照樣顯示但撳咗冇反應

- **位置**：`js/core/actions.js:15`、`index.html:41`、`js/core/i18n.js:54-55`
- **描述**：pill 永遠喺 markup 入面，`toggleLang` 直接 `setLang(ZH_HK_LANG)`。如果 `locales/zh-HK.js` 冇載入（plan 決定唔加入 `LATE_BOOT_SCRIPTS`），`setLang` 只會 `console.warn('[i18n] no locale for zh-HK')` 然後 return。
- **重現（已驗）**：將 HEAD 解壓到 scratch、刪走 `locales/zh-HK.js`，`lifeuk.uiLang = "zh-HK"`，reload 後撳 pill：
  `{"before":{"lang":"en","pill":"中","visible":true},"after":{"lang":"en","pill":"中"},"warns":["[i18n] no locale for zh-HK"]}`
- **失敗情境**：冇 SW 嘅首次載入或者 SW 未 activate 期間 network 斷咗一個 file（S-014 / W-010 已經處理過同類 cutover）；另外 `en.js` 走 late-boot 重載嘅路徑（見 S-041）都會令 zh-HK 永遠缺席。用戶見到一個可撳嘅掣，撳極都冇反應、冇提示。可能性低，但係「可見控件靜默失效」。
- **方案 A（推薦）**：`applyLanguage()`（或 `startApp()`）入面 `byId('langBtn').hidden = !hasLocale(ZH_HK_LANG);` — 冇 locale 就唔顯示 pill。一行、冇新狀態；加一個 upgrade-test case（current shell 刪 `zh-HK.js` → pill hidden、冇 page error）。
- **方案 B**：將 `locales/zh-HK.js` 加入 `LATE_BOOT_SCRIPTS`（`ready: () => hasLocale(ZH_HK_LANG)`）。Trade-off：同 plan §0「zh-HK.js 唔加入 `LATE_BOOT_SCRIPTS`」相反，而且 zh-HK 失敗會觸發整個 reload + fallback 流程，代價大過收益。
- **推薦**：A。

### W-014 — `<html lang="zh-HK">` 下英文題目／選項冇標 `lang="en"`

- **位置**：`js/core/i18n.js:62`（`document.documentElement.lang = getLang()`）；受影響容器 `index.html:188` `#qText`、`index.html:192` `#optionsContainer`、答案／解說、Study fact 英文內容、`data.chapters` 英文章節名
- **描述**：Q1 決定題目、選項保持英文，但切到 zh-HK 之後整頁 `lang` 變 `zh-HK`，英文內容冇覆寫 `lang`。
- **失敗情境**：VoiceOver / TalkBack / NVDA 按 `lang` 揀語音 —— zh-HK 用戶用 screen reader 做題，英文題目同選項會用粵語／中文語音讀（逐個字母或者亂讀），等於核心內容唔可用。（反方向嘅舊問題：en 模式下 `#qYue` 等廣東話翻譯都冇 `lang="zh-HK"`，v0.59 前已存在，可以一齊修。）
- **方案 A（推薦）**：靜態容器直接加屬性：`#qText`、`#optionsContainer`、答案英文部分 `lang="en"`；`#qYue`、`#ansYue`、fact `yue` 段 `lang="zh-HK"`。屬性唔隨語言變，冇 runtime 成本；`lang-switch-test` 加一句 `closest('[lang]').lang === 'en'` 檢查。
- **方案 B**：喺 render function（`renderQuestion`、`factCardHtml`）動態加 `lang`。Trade-off：分散喺多個 file，易漏。
- **推薦**：A（動態生成嘅 fact card 用 B 補）。

## 🟢 Suggestions

### S-041 — current shell + `en.js` 載入失敗：`zh-HK.js` 拋 `ReferenceError`

- **位置**：`locales/zh-HK.js:8`
- **描述 / 已驗**：current shell 刪走 `locales/en.js`：page errors = `["LOCALES is not defined","LOCALES is not defined"]`（reload 前後各一次），之後 S-014 fallback 文字照常出現。功能冇壞，但 S-014 / W-010 測試一向要求「no page errors」，而呢個組合（current shell + `en.js` 缺）冇 case 覆蓋；而且成功 late-load `en.js` 之後 zh-HK 永遠唔會有（連帶 W-013）。
- **方案 A**：`upgrade-test` 加 `i18nBootFailure(b, { tag: 'current shell, locale missing', shell: 'index.html', missing: 'locales/en.js' })`，記錄呢個已知錯誤（regex 豁免）。
- **方案 B**：`zh-HK.js` 開頭 `if (typeof LOCALES !== 'undefined')` guard。Trade-off：locale file 加邏輯，同 en.js「純資料」風格唔一致。
- **推薦**：A（只補測試，記錄係已知行為），配合 W-013 方案 A 已經足夠。

### S-042 — M4 media query 都會縮細 en 嘅 `.result-sub`

- **位置**：`css/screens/results.css:71-74`
- **描述**：`@media (max-width: 360px) { .result-sub { font-size: var(--fs-sm); } }` 冇限語言，en 喺 ≤ 360px 都由 13px 變 12px。M4 只講「窄屏用細一級 token」，冇明講要唔要影響 en；註解卻寫「so the zh-HK pass line…」。
- **方案 A**：`:root:lang(zh-HK) .result-sub` 限定 zh-HK（`<html lang>` 已經跟語言）。
- **方案 B**：保持現狀，改註解寫明 en 都受影響（兩種語言一致亦合理）。
- **推薦**：由用戶揀；預設 B（改註解），en 細 1px 冇壞處。

### S-043 — `GUARD_WAIT_MS = 400` 寫死，冇跟 `SCREEN_CHANGE_CLICK_GUARD_MS`

- **位置**：`tests/lang-switch-test.js:21, 180`
- **失敗情境**：日後 guard 改成 ≥ 400ms，第一下 click 同 dblclick 之間就唔再隔開 guard window，測試意義改變但唔會 fail。
- **方案 A（推薦）**：`const wait = await pg.evaluate(() => SCREEN_CHANGE_CLICK_GUARD_MS) + GUARD_MARGIN_MS;`
- **方案 B**：保持常數但加 assert `GUARD_WAIT_MS > SCREEN_CHANGE_CLICK_GUARD_MS`。

### S-044 — Pill 測試只驗可見尺寸，冇驗 44px hit area

- **位置**：`tests/lang-switch-test.js:53-54`
- **描述**：mockup / CSS 嘅重點係 `::before` 將 hit area 擴到 ≥ 44px（36+12 × 26+20 = 48 × 46），但測試只 assert `w >= 36 && h >= 24`。刪咗 `::before` 測試照過。
- **方案 A（推薦）**：`document.elementFromPoint(r.left - 5, cy)` 同 `(cx, r.top - 9)` 應該 `=== pill`。
- **方案 B**：讀 `getComputedStyle(pill, '::before')` 嘅 `inset`。Trade-off：只驗 CSS 值，唔驗實際命中。

### S-045 — `checkResultSub`（M4）依賴測試機有 CJK 字體

- **位置**：`tests/lang-switch-test.js:190-202`
- **描述**：用 Range 量「方為合格。」換唔換行；冇 CJK 字體時字寬係 tofu／fallback，結果因環境而異（本機過，CI image 換字體就可能 flaky）。
- **方案 A**：測試開頭量一個中文字寬度／`document.fonts.check(...)`，冇 CJK 字體就 log skip。
- **方案 B**：喺 HANDOFF 寫明測試環境要求 `fonts-noto-cjk`。

### S-046 — `lang-switch-test.js` 嘅 `main()` 約 150 行

- **位置**：`tests/lang-switch-test.js:38-187`
- **描述**：HANDOFF 規則 function ≤ 30 行（`structure-test` 只掃 `js/`）。現有測試（例如 `i18n-test` `runtimeChecks`）都有長 function，所以唔算 regression，但呢個 file 已經自然分段（pill / Home / Quiz / exam timer / modal / Result / Flagged / Study / double tap）。
- **方案 A**：每段抽成 `async function checkXxx(pg, ctx)`。
- **方案 B**：保持，跟現有測試風格。
