### 🟡 Warning

#### W-024 —（舊有，唔計分）計時到 0 嗰陣 confirm modal 仍然開住，蓋住結果頁
- **位置**：`js/screens/examTools.js:38`（`examTick`）→ `js/screens/result.js:17`（`finishExam`）
- **描述**：Submit / Leave modal 開住時倒數到 0，`finishExam` 轉去結果頁但冇 call `closeConfirm()`。Modal 留喺結果頁上面，`confirmOnOk` 仍然係 `finishExam`。
- **重現**（`main` `cbbee5f` 同 `1ada9d2` 結果一樣）：最後一題撳 Submit → 等 timer 到 0 → 結果頁有「時間到」提示 + modal 仲開住 → 撳 Submit → `finishExam` 再跑一次，`examTimeUp` 已經清咗，**「時間到」提示消失**；`recordExamResults` 亦重跑。Leave modal 嘅情況撳 Leave 會由結果頁跳返 Home。
- **影響**：少見（要喺最後幾秒開 modal），但會令時間到提示消失，記錄亦會重做一次。唔係今次 diff 引入。
- **方案 A**（推薦）：`finishExam` 開頭 `if (isConfirmOpen()) closeConfirm();`（或者喺 `examTick` 嘅 time-up 分支做）。Trade-off：1 行；`closeConfirm` 會將 focus 還原去收埋咗嘅 opener，然後跌落 `body`，同 OK 路徑一樣。
- **方案 B**：`finishExam` 做成 idempotent（session 已經 finish 就 return）。Trade-off：處理到重跑，但 modal 仍然遮住結果頁。
- **推薦**：A，加一個 examtools-test case（開 modal → `examDeadline` 設做過去 → `examTick()` → modal 已關、提示仍然顯示）。另開 ticket，唔阻今次 merge。
