### 🟡 Warning

#### W-011 — `factMastery` 遇到零來源時 `derived: true`

- **位置**：`js/domain/mastery.js:26-29`
- **描述**：`derived: m.mastered === m.total` 喺 `f.src = []` 嘅時候係 `0 === 0` → `true`。實測 `factMastery({ src: [] })` 返 `{"mastered":0,"total":0,"pct":0,"derived":true}`。
- **影響**：而家 236 個 fact 全部有 ≥ 1 個來源（已驗證），所以未觸發。但係只要將來有一個冇來源嘅 fact（資料編輯、新 chapter），佢就會自動當「🏆 已掌握」、變暗、喺 Hide mastered 消失、計入 `🏆 n / 236`，Practise 掣仲會開一個 0 題嘅 session。數值邊界（零值）唔應該靠資料剛好啱。
- **方案 A**（推薦）：domain 守衛 `derived: m.total > 0 && m.mastered === m.total`，factmastery-test 加一條 `factMastery({ src: [] }).derived === false`。
  - Trade-off：一行改動，邏輯自己完整；空來源 fact 仍然會出 Practise 0 掣（可以另外喺 `factSourceRowHtml` 用 `f.src.length` 判斷）。
- **方案 B**：資料不變量測試 `STUDY.every(f => f.src.length > 0)`（例如加入 diff-test）。
  - Trade-off：保護到全部依賴 `f.src` 嘅地方（session、來源列），但 domain 函數本身仍然唔安全。
- **推薦**：A，最好 A + B 一齊做。

```js
// js/domain/mastery.js
// a Study fact's Practice mastery: its source questions (f.src); `derived` = every one of them is 🏆.
// A fact with no source question is never derived (0 / 0 is not "all mastered").
function factMastery(f) {
  const m = masteryOf(f.src.map(questionByKey));
  return { ...m, derived: m.total > 0 && m.mastered === m.total };
}
```
