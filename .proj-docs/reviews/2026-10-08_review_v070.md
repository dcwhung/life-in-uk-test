## 問題清單

### 🟢 S-104 — study-test 嘅 timeline dot assertion 量唔到 `align-self: start` 被拎走

- 位置：`tests/study-test.js`（v0.70 timeline dot block，`contentMid = r.top + padTop + (r.height - padTop) / 2`）
- 描述：assertion 用 `.tl-year` 嘅 content box 中間代表「年份字中間」。呢個前提只係喺 `.tl-year` 冇被 grid stretch 時成立。實測拎走 `align-self: start` 之後，`.tl-year` 拉到成張卡咁高（例如 264px），dot 落咗去卡中間（離字 ~125px），但 content box 中間同 dot 仍然重合，所以 study-test 照 PASS。
- 影響：今次 fix 嘅三個關鍵 CSS 之中，有一個冇 regression 保護；將來有人整理 CSS 刪咗 `align-self`，dot 會走位而 CI 唔會發現。
- 方案 A（推薦）：用文字本身做參考。`range.getClientRects()` 嘅 top / bottom（或者加 cap-trim 之後 content box 高度 ≈ 行數 × cap height）同 content box 比較，例如 assert `r.height - padTop` ≤ 行數 × line-height + 0.5，再沿用現有 off 檢查。改動細，一個 assertion。
- 方案 B：直接 assert `getComputedStyle(e).alignSelf === 'start'`。最平，但係測 implementation 唔係效果。
- 推薦：A。

### 🟢 S-105 — W-022 嘅 `:not(.t-note)` 同兩段 home.css comment 已經過時

- 位置：`css/screens/home.css` 133–139
- 描述：v0.70 之後，空嘅錯題 tile 冇 `.t-note`（只出「Nothing to review yet」），空嘅 Flagged tile 本身都冇 `.t-note`，所以 `.my-tile.empty > :not(.t-note)` 嘅 `:not()` 已經冇作用；上面 comment 仲寫「not the wrong answers note (it explains the tile, so it keeps full contrast at 0)」，同而家行為相反。`.my-tile .t-note` 嘅 comment「set apart from the count line above it」亦已經冇 count line（上面係 title `<b>`）。
- 影響：誤導之後改 Home tile 嘅人（以為 0 題時仲有 note 要保持對比度）。純 maintainability，冇視覺影響。
- 方案 A（推薦）：selector 簡化做 `.my-tile.empty > *`，兩段 comment 改寫成 v0.70 行為（空 tile 全部淡化；note 只喺有錯題時出，同 title 隔 6px）。lang-switch-test / v068 QA 已經檢查「全部 0.6」，唔使改 test。
- 方案 B：保留 `:not(.t-note)` 做 defensive，只改 comment 講明「v0.70 起空 tile 冇 note，保留 :not() 以防將來加返」。
- 推薦：A（YAGNI；test 已 cover）。
