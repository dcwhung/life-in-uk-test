#### S-190 — structure-test 截圖路徑檢查漏網 + template literal 誤報

- **位置**：`tests/structure-test.js:365-370`
- **描述**：regex `/screenshot\(\s*\{\s*path:\s*['"`]/` 只認 `path` 係第一個 key 兼直接係字串。reviewer 試過：
  - 漏網：`screenshot({ fullPage: true, path: 'a.png' })`、`const p = 'a.png'; screenshot({ path: p })`、`screenshot({ path })`、`path.join('shots', 'a.png')`、`{ "path": 'a.png' }`
  - 誤報：`` screenshot({ path: `${__dirname}/a.png` }) ``（絕對路徑但會 fail）
- **影響**：低。而家 0 個漏網；將來有人改 option 次序或者用變數，root `shot-*.png` 會再出現（`.gitignore` 會擋住 commit，所以只係 cwd 污染）。
- **方案 A**：改做正向白名單：抽每個 `screenshot({…})` 嘅 `path:` 值，要求以 `path.join(__dirname` 或 `path.join(SHOTS` 開頭。
  - Trade-off：仲係 regex，但漏網只剩跨行 / 動態 object。
- **方案 B**：喺測試共用 helper（例如 `tests/tools/shot.js` 出 `shot(pg, name, opts)`，內部 `path.join(__dirname, '..', name)`），structure-test 禁止直接 `.screenshot(`（除 helper 本身）。
  - Trade-off：最嚴、一個地方管路徑；要改 11 個檔。
- **推薦**：A（細改動，夠用）。

#### S-191 — R4 靠 English regex 配對，可以改做「地方議會只准喺 note」

- **位置**：`tests/content-guard-test.js:102-114`
- **描述**：R4 只喺 English 含 `local council`（或 fact 含 electoral registration officer）先查 `yue` / `oy`。冇 "local" 嘅 "county council" / "town council" / "council tax"、"local authority" 或者 English 字中間換行 / 雙空格都唔會觸發；`note` 亦唔查。而家 data 冇呢啲字，所以 0 漏網，4A 冇被誤殺。

  - Trade-off：要維護排除清單。
- **推薦**：A。
