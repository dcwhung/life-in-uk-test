## 總評

核心做法乾淨：大字 = `<html data-font-size="large">` + `tokens.css` 一段 override，20 個 `--fs-*` token 全部 +2px（reviewer 用 computed style 逐個對過）；因為 PR-A 已將所有字號 token 化，呢個 PR 嘅 CSS 改動好細（L4b / L5 四行 + S-193 一行）。`getFontSize()` 唔認識嘅值當細字、`setFontSize()` 有白名單、冇揀之前唔寫 storage，同 `uiLang` 一樣嘅寫法。C3 題號量度（`textLineCount()` 用 Range 數行）簡單易明，`data-full` / `data-short` 經 `escapeHtml()`（有 escape `"`）先入 attribute，仲順手將之前未 escape 嘅 `t()` 輸出 escape 埋。`chooseFontSize` 跟 `chooseLang` 一樣：modal 開住唔做嘢、先閂 popover、同一個值唔再 render。TDD 有做（test commit 先）。

### 🟡 W-056 — Plan「設定目標」畫面大字爆版（Q3 未做到）

- **位置**：`css/screens/plan.css`（`.plan-stack .plan-presets`、`.plan-ticks`）、`css/screens/home.css:2` `.mode-grid`（`.plan-levels` 用佢）；`tests/fontsize-test.js` `checkNoSideScroll()` 冇呢個畫面
- **描述**（reviewer 量度，`openPlanGoal()`）：

  | 情況 | 頁面多出嘅闊度 | chip 被切 | 刻度字重疊 |
  |---|---|---|---|
  | 大字 en 320 | **14px**（`.plan-levels` 第 3 張「Advanced」卡凸出畫面） | 「1.5 months」 | 3 對 |
  | 大字 en 360 / 375 / 390 | 0 | 「1.5 months」（切咗 10 / 7 / 3px） | 0 |
  | 大字 zh-HK 320 | 0 | — | 2 對 |
  | 細字（全部） | 0 | — | 0 |

  原因：`.mode-grid` 係 `1fr 1fr 1fr`（= `minmax(auto, 1fr)`），「Intermediate」17px 粗體嘅 min-content 撐闊咗 grid（CUI-0012 dots 都係同一個原因）；chip `white-space: nowrap`，連 `padding-inline` 都唔夠位；`.plan-ticks span` 闊度 0 + `nowrap`，字大咗就撞埋。
- **影響**：每個建立學習計劃嘅用戶都會經過呢頁；320px 英文大字要打橫 scroll 先見到「Advanced」。同 Q3「逐個爆版位加 `[data-font-size="large"]` override，截圖測試鎖死」唔一致。呢個屬 M2 以外嘅新 layout 改動，**要先問用戶**。
- **方案 A（推薦）**：只加大字 override。`:root[data-font-size="large"] .plan-levels { grid-template-columns: repeat(3, minmax(0, 1fr)); }`，卡內 `overflow-wrap: anywhere` / `hyphens: auto`（en「Intermedi-ate」）；chip 大字時 `white-space: normal`，或者 locale 改短「1.5 mo」；刻度大字 ≤ 359px 只顯示單數格（`:nth-child(even) { visibility: hidden }`）。再將 `planGoal` 加入 `checkNoSideScroll()` 同 chip `scrollWidth` assert。好處：同 L4b / L5 一樣只影響大字。壞處：要用戶睇過新樣（建議先出 320 / 375 截圖）
- **方案 B**：大字 ≤ 359px 時程度卡改成直排一欄（icon 喺左、字喺右）。好處：字唔使斷，最易讀。壞處：頁面長咗，layout 改動比較大
- **推薦**：A（改動最細，同 M2 嘅做法一致）；先畀用戶睇截圖

### 🟡 W-057 — 混合檔案：舊 `store.js` 令 Home 空白，舊 `i18n.js` 令 ⚙ 撳唔開

- **位置**：`js/main.js:71` `applyFontSize()`；`js/core/actions.js:14` `syncFontSetting()`；`js/core/i18n.js:72` `getFontSize()`；`js/screens/quiz.js:115` `t('quiz.questionOfShort')`
