## 問題清單

### 🟡 W-382 混版（HTTP cache）：舊 `planGoal.js` / `planProgress.js` + 新檔案會 throw

- **位置**：`js/domain/plan.js`（刪 `PLAN_GOAL_MODE`、`planGoalLimits`）、`index.html`（刪 `#planDateNote`）、`js/main.js` `removeLegacyPlanMarkup()`
- **描述**：項目一直有測「current shell + 一個舊檔」（upgrade-test 9–11，W-057）。今次只處理咗「舊 shell + 新 JS」。Reviewer probe（scratch script，current files + `origin/main` 嘅單一檔）：
  - 舊 `js/screens/planGoal.js`：`openPlanGoal()` → `Cannot set properties of null (setting 'hidden')`（`setShown('planDateNote', …)`；佢之後仲會撞 `PLAN_GOAL_MODE is not defined`）。新計劃同更改目標兩個模式嘅表單都 render 唔到。
  - 舊 `js/domain/planProgress.js`：Update → `PLAN_GOAL_MODE is not defined`，撳咗冇反應。
  - 舊 `plan.js` / `planSchedule.js` / locale 冇 throw。
- **影響**：冇 SW 控制時（第一次訪問、SW 未裝好），HTTP cache（GitHub Pages max-age=600）最多 10 分鐘內，溫習計劃表單壞咗。同 W-057 同一類。
- **方案 A**（推薦）：多保留一個版本嘅相容 shim：`plan.js` 留 `const PLAN_GOAL_MODE = { create: 'create', edit: 'edit' }` 同 `function planGoalLimits() { return { minDaysAhead: PLAN_MIN_DAYS, minStudyDays: PLAN_MIN_STUDY_DAYS }; }`，都標 `// W-382: for a cached pre-v2.1.0 planGoal.js / planProgress.js; remove after v2.2`；`index.html` 留空嘅 `<p class="plan-muted" id="planDateNote" hidden></p>`（冇 `data-i18n`）；`removeLegacyPlanMarkup()` 改為淨係 `removeAttribute('data-i18n')` + 清空文字，唔好 `remove()`。upgrade-test 加一段「current shell + v2.0.2 planGoal.js / planProgress.js」：打開表單、Update，冇 page error。好處：同 W-057 做法一致，有 test 守住。代價：多兩個 deprecated 名，要記住下個版本刪。
- **方案 B**：接受呢個短暫風險，喺 HANDOFF 記低（「v2.1.0 混版最多 10 分鐘表單壞，reload 後正常」），upgrade-test 唔加。好處：冇 shim。代價：同項目一直以來嘅混版承諾唔一致，而且係 Critical ticket 嘅同一個畫面。
