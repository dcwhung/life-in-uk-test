### 🟡 Warning

#### W-067 — fact 練習「↩ Back」返 Study：`--study-top-h` 係 0，`flashStudyFact` 將卡留喺 pinned block 下面

- **位置**：`js/screens/study.js:534-540`（ResizeObserver 寫 `--study-top-h`）× `js/screens/sideSession.js` `SESSION_RETURNS.study`（`showScreen` → `renderStudy` → `scrollTo(ret.scrollY)` → `flashStudyFact`）× `css/screens/study.css:163`（`scroll-padding-top`）
- **描述**：去 quiz 時 `#screenStudy` 變 `display: none`，ResizeObserver 回報 `offsetHeight` 0 → `--study-top-h: 0px`。返嚟時 `flashStudyFact` 同步 call `scrollIntoView({ block: 'nearest' })`，RO callback 要等下一個 rendering step 先更新，所以嗰一刻 `scroll-padding-top` 只係 header（58px）。卡頂如果喺 header 同 pinned block 之間（即係被 block 遮住），`nearest` 當佢「已經喺 view 入面」，唔會捲。
- **重現（reviewer probe，390×844 en 細字，People tab）**：卡頂捲到 header 下 30px（block 底 277px）→ `startFactPractice(id)` → `returnFromSideSession()` → 卡頂 **88px**、block 底 277px（卡頂 + badge 行被遮，flash 都睇唔到上半）；對照組（唔離開 Study 直接 `flashStudyFact`）→ 卡頂 277px。RO 喺之後兩個 frame 先變返 186px。
- **影響**：用戶撳卡底「▶ 練習」（卡頂多數已經捲咗上去），做完返嚟，`flashStudyFact` 本來就係要令張卡完整出現 —— v1.6.0 喺 header 下面做到，v1.6.1 變咗被 block 遮。HANDOFF 寫「`flashStudyFact` 唔會俾 pinned block 遮」，對真返回路徑唔成立。`study-sticky-test` `anchorChecks` 喺 Study 入面直接 call `flashStudyFact`（var 已經量好），所以冇捉到。
- **方案 A（推薦）**：抽 `studySyncTopHeight()`（`offsetHeight` 寫入 `--study-top-h`），RO callback 同 `flashStudyFact` 開頭（或者 `SESSION_RETURNS.study` 喺 `renderStudy` 之後）都 call；`.study-top` 唔存在就 return（舊 shell）。Trade-off：一次同步 layout read（本身 `scrollIntoView` 都會 force layout，冇額外成本）。
- **方案 B**：RO callback 見 `offsetHeight === 0`（screen 隱藏）就唔寫，保留上次值。Trade-off：最少改動，但隱藏期間轉語言 / 字號，返嚟第一下用舊高度（差幾十 px）；同 Flagged 做法分歧。
- **Test**：`study-sticky-test` 加真路徑：捲到卡頂喺 block 下面 → `startFactPractice` → `returnFromSideSession` → 同步 assert 卡頂 ≥ block 底 − 1（紅燈：而家 HEAD 會 fail）。

#### W-068 — 細 mon pinned 區（header + block）最多佔 62% viewport，只有橫放 ≤ 500px 先 unpin

- **位置**：`css/screens/study.css:155-168`
- **量度（reviewer probe，捲到底，pinned = 58px header + block；% = 佔 viewport）**：

| viewport | 最差 tab | block | pinned 佔 |
|---|---|---|---|
| 320×568 en 大字 | People | 297px | **62%**（Geo 56%、Chapters 50%） |
| 320×568 zh-HK 大字 | Geo / People | 235px | 52% |
| 320×568 en 細字 | People | 247px | 54% |
| 360×640 en 大字 | People | 264px | 50% |
| 375×667 zh-HK 大字 | People | 239px | 45% |
| 390×844（全部組合） | People | ≤ 231px | ≤ 34% |

- **影響**：320×568（iPhone SE 1 代 / 5s，最高 iOS 15；standalone PWA）en 大字 People tab 只剩 ~213px 睇 list（大約一張 fact 卡嘅一半）。375×667（SE 2 / 3，仍然支援）最差 45%，可接受。Safari 瀏覽器模式（有網址列）比例再高。
- **方案 A（推薦）**：喺現有 RO callback（再加 `resize` listener，因為 viewport 變但 block 唔變唔會觸發 RO）計 `header + block > innerHeight × 0.5` → `.study-top.is-tall { position: static }` + `scroll-padding-top` 用 header-only。Block 高度唔受 sticky / static 影響，唔會來回跳。Trade-off：320×568 en 大字（Chapters / Geo / People）、360×640 en 大字 People 會 unpin，即係用戶「5 個 tab 都 pin」喺呢啲組合唔成立 —— **要問用戶**；threshold 50% 係建議值（360×640 en 大字 People 剛好 50%）。
- **方案 B**：pin 嘅時候 chip 行改單行橫 scroll（`flex-wrap: nowrap; overflow-x: auto`），block 收到 ~140–150px，任何 mon 都 ≤ 37%。Trade-off：改咗視覺（chip 要打橫掃，部分 chip 睇唔到），同用戶截圖 baseline 唔同，要用戶睇過。
- **方案 C**：`@media (max-height: 600px)` CSS-only unpin。Trade-off：最簡單、冇 JS，但唔理語言 / 字號 / tab（320×568 zh-HK 細字 Timeline 只佔 36% 都 unpin）。
- **Block 唔 block**：**唔 block merge**。用戶明確要求 5 個 tab 都 pin；62% 只出現喺最細 + en 大字 + People / Geo，list 仍然可以捲、冇內容被永久遮、橫放已有 escape；呢個係體驗取捨，應該由用戶揀（建議方案 A threshold 50%），唔係 bug。

// the pinned block's height as --study-top-h (scroll-padding-top). Measured on demand too: while Study is hidden
// (a fact session) the observer reports 0, and flashStudyFact runs before the observer's next callback (W-067)
function studySyncTopHeight() {
  const top = document.querySelector('#screenStudy .study-top');
  if (top) document.documentElement.style.setProperty('--study-top-h', `${top.offsetHeight}px`);

const studyTop = document.querySelector('#screenStudy .study-top');
if (studyTop && typeof ResizeObserver !== 'undefined') new ResizeObserver(studySyncTopHeight).observe(studyTop);

function flashStudyFact(id) {
  const el = document.querySelector(`#studyContent .fact[data-fact-id="${id}"]`);
  if (!el) return;
  studySyncTopHeight(); // W-067: the screen was hidden a moment ago
  el.scrollIntoView({ block: 'nearest' });
  // …
}
