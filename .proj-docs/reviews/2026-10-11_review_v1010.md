#### S-165 — table 格「• 」備注嘅 hanging indent 假設「• 」啱啱 0.9em 闊

- **位置**：`css/components/note.css:26`（`.note-cell-sub.bullet`）、`js/components/tags.js` `noteCellHtml()`
- **描述**：換行之後嘅文字對齊位係 `2 × 0.9em − 0.9em + 「• 」嘅闊度`，所以要「• 」啱啱 0.9em 先對得齊。reviewer 喺 Chromium 量過（`.note-cell-sub` 字 11px）：Inter / 系統字型 = **0.844em**（差 0.6px，測試 1px 容差過到）、DejaVu Sans = 0.909em、Noto Sans CJK HK = **0.601em**（差大概 3.3px）。真機（iOS SF / PingFang、Android Roboto / Noto）闊度唔同，第二行可能同第一行文字差 2–3px。普通筆記行（`.rv-note-line`）一早就係為咗呢個原因，用咗固定闊度嘅 `.note-mark` box
- **影響**：純視覺，差幾 px，唔會壞 layout；`note-indent-test` 嘅結果靠 CI 用邊隻字型
- **方案 A**：`noteCellHtml` 將「• 」包入固定闊度 span（同 `.note-mark` 一樣：`display:inline-block; width: var(--cell-bullet-indent); text-indent:0`），每隻字型都一定對齊。代價：多一個 span，`textContent` 都仲係「• …」，測試嘅 `afterMark` 要改用 span 嘅 `nextSibling`
- **方案 B**：維持現狀（同 mockup / 用戶確認嘅 CSS 一樣），喺 HANDOFF 寫明係按字形闊度估嘅
- **推薦**：A（同現有 `.note-mark` 做法一致），可以下個 patch 先做

## 修訂代碼（S-165 方案 A 參考，未套用）

```js
// js/components/tags.js — "• " remark: the marker sits in a fixed-width box like .note-mark,
// so a wrapped line lines up with the text in any font
const NOTE_CELL_BULLET = /^•\s+/;
function noteCellSubHtml(remark) {
  const mark = remark.match(NOTE_CELL_BULLET);
  if (!mark) return `<span class="note-cell-sub">${escapeHtml(remark)}</span>`;
  return `<span class="note-cell-sub bullet"><span class="note-cell-mark">• </span>${escapeHtml(remark.slice(mark[0].length))}</span>`;
}
```

.note-cell-mark { display: inline-block; width: var(--cell-bullet-indent); text-indent: 0; }
