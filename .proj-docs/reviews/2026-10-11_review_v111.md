### 🟡 Warning

#### W-052 — 時間線直線喺每兩張卡之間斷 8px（margin collapse）

- **位置**：`css/screens/study.css` `.tl-item` / `.tl-body .fact { margin-bottom: var(--space-4) }`
- **描述**：`.tl-item` 而家係普通 block（`position: relative` 唔會開 BFC），冇 padding-bottom / border-bottom，所以 `.fact` 嘅 8px `margin-bottom` 穿過 `.tl-body` 同 `.tl-item` collapse 咗出去，變咗 item 之間嘅空位。直線係 `.tl-item` 嘅 `border-left`，所以喺 72 個相鄰 item 之間全部斷 8px（下一個圓點個環蓋住約 3px，見到約 5px 空位；放大截圖逐 pixel 量過）。舊 grid 版本 0 個空位（grid item 唔 collapse margin）。
- **影響**：時間線變咗一段段，同 commit 註解「one item = year + card, so it runs on」同舊版連續直線唔一致；用戶批嘅 preview 如果係連續線，即係實作同 proposal 唔一樣。`timeline-test` 量嘅「above = 10px」由前一張卡底量起，所以有冇 collapse 都係 10px，捉唔到。
- **方案 A（推薦）**：`.tl-item` 加 `display: flow-root`（開 BFC，margin 留喺 item 入面）。一行改動，試過：空位 0、10 / 8px、圓點、overflow 全部唔變。
- **方案 B**：`.tl-body .fact { margin-bottom: 0 }`，`.tl-item { padding-bottom: var(--space-4) }`。效果一樣，但係要喺兩個地方表達同一個間距，同 `.fact` 預設 margin 唔夾。
- **測試**：`timeline-test` `checkYearLayout` 加一條：相鄰 `.tl-item`（`nextElementSibling`）`top === 前一個 bottom`（± 0.5px），即係直線連續。

#### S-172 — 唔支援 `text-box` 嘅 browser 年份上下間距變 12 / 11.4px

- **位置**：`css/screens/study.css` `.tl-year`（刪咗嘅 `@supports not (text-box: trim-both cap alphabetic)`）
- **描述**：冇 trim 嗰陣 content box 係成個 line box（12px × 1.2 = 14.4px），比 cap 高大約 5.7px，所以字形上面多約 2.3px、下面多約 3.4px。圓點因為量 content box 中間，只偏約 0.6px，冇問題。
- **影響**：iOS ≤ 18.1、Chrome ≤ 132、Firefox 嘅用戶見到嘅間距唔係用戶調過嘅 10 / 8px（大約 12 / 11.4px）。唔會爆 layout。

  ```css
  /* browsers without text-box: the content box is the whole line box (~2.3px above / ~3.4px below the caps),
     so take that off the padding to keep the 10px / 8px the user picked */

    .tl-year { --tl-year-above: 0px; --tl-year-below: var(--space-1); }

  ```

- **描述**：CI 用嘅 Chromium 支援 `text-box`，所以後備嗰段 CSS 永遠唔會生效；而家只靠 developer 同 reviewer 人手注入 `text-box: normal` 量。將來有人改 `--tl-year-above` / `--tl-year-below` 或者 `.tl-year` 嘅 `line-height`，後備會靜靜咁走樣。
