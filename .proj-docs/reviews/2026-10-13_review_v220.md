## 問題清單

### 🔴 C-007 — 手機一屏高 Quiz：矮啲嘅手機（高度 ≥ 500px）選項 panel 縮到 0px，答唔到題

- **位置**：`css/components/fit.css`（`@media (max-width: 1023px) and (min-height: 500px)`，`.screen.is-fit-phone .fit-panel { min-height: 0 }`）、`css/screens/quiz.css`（`#screenQuiz.is-fit-phone > * { flex: none }`、`> .quiz-scroll { flex: 1 1 auto; min-height: 0 }`）、`js/screens/quiz.js` `buildQuizPhone`
- **描述**：題目卡（進度條、24 粒圓點、計數、題號行、題目、翻譯）係 `flex: none`，唔會縮；選項 panel 攞剩低嘅高度，冇下限。Viewport 高過 500px 嘅 media query 就開，唔理剩低幾多位。
- **Reviewer 實測**（Playwright，`zh-HK`，翻譯開）：

  | Viewport | 字 | 結果 |
  |---|---|---|
  | 375 × 553（iPhone SE / 8，Safari 有 toolbar） | 細 | Exam 1–3 72 題：**13 題 panel 0px**，71 題 < 60px，最大 61px |
  | 375 × 553 | 大 | **27 題 0px**，72 題全部 < 60px |
  | 320 × 568 | 大 | 最長題目：panel 0px，頁面多咗 56px 碌但係選項喺 0px panel 入面，碌唔出 |
  | 360 × 640 | 大 | panel 0px |
  | 375 × 667 | 大 | 20–28px |
  | 390 × 664 | 細／大 | 101–169px／40–144px（勉強用到） |

  截圖（375 × 553 細字）：「A Inequity」得返半行，其餘選項喺一條大約 40px 嘅縫入面碌。
- **影響**：Practice / 錯題 / 旗標 / 計劃練習 / 記憶法 ② 試：題目長或者開咗翻譯，**用戶揀唔到答案**；panel 有少少高度時都要喺一條縫入面碌。Exam 冇翻譯，但係大字照樣得 27–43px。`main` 係成頁碌，冇呢個問題，所以係 regression。`phone-quiz-test` 淨係行 390 × 844，`controlsReachable` 冇捉到。
- **方案 A（建議）**：固定唔到就退返成頁碌。`arrangeQuizPhone` / `fitQuiz` 量 panel：`panel.clientHeight < QUIZ_PHONE_MIN_PANEL_PX`（例如 2 粒選項高，用 token 計）就拎走 `.is-fit-phone`（同 desktop 嘅 `fitSteps` 一樣係逐步退），resize / 換題再量。好處：任何高度都安全，大手機保留 mockup 效果。代價：要多一個 class 狀態同 test。
- **方案 B**：題目卡都可以縮：`.q-card { flex: 0 1 auto; min-height: 0; overflow-y: auto }`，panel 加 `min-height: clamp(...)`。好處：純 CSS。代價：張卡同 panel 兩個碌位，同 rev 6「題目卡固定」唔一致，要問用戶。
- **方案 C**：將斷點升到 `min-height: 700px` 左右。最簡單，但係 iPhone SE／細 Android 喺 Safari / Chrome 入面就冇咗一屏高，而且大字 + 長題喺 700px 都未必夠；只係減少，唔係解決。
- **推薦**：A；同時加 W-078 嘅 test。

```js
// js/screens/quiz.js — 方案 A 草稿（示意；常數名同 token 由 developer 定）
const QUIZ_PHONE_MIN_PANEL_PX = 120; // 至少見到兩粒選項；或者由 --space-* token 計
function arrangeQuizPhone(desktop) {
  if (desktop) return;
  if (!quizPhone) quizPhone = buildQuizPhone();
  deskFill(quizPhone.panel, QUIZ_PHONE_PART_IDS.map(byId));
  const screen = byId('screenQuiz');
  screen.classList.add('is-fit-phone');                    // 先試一屏高
  if (quizPhone.panel.clientHeight < QUIZ_PHONE_MIN_PANEL_PX) {
    screen.classList.remove('is-fit-phone');               // 放唔落：退返成頁碌（main 嘅行為）
  }
  topQuizPanelOnNewQuestion(quizPhone.panel);
}
```
