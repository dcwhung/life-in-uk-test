## 問題清單

### 🟡 W-040 — 舊 cache `index.html` + v1.0.4 JS：Plan Day 畫面 TypeError（只渲染一半）

- 位置：`js/screens/planDay.js` `planShowRest`（`setShown('planRestEmoji', …)`）、`planShowMonthNav`（`byId('planCalBtns').contains`）
- 描述：HANDOFF「SW 換版混合頁面」（CUI-0004 類）講明舊 SW cache 嘅 `index.html` 可以配新 JS。v1.0.3 shell 冇 `#planRestEmoji` / `#planCalBtns`。`renderPlanDayInfo` **每日**（唔只休息日）都 call `planShowRest`，`setShown` 對 `null` set `.hidden` → `TypeError`。Schedule 嗰邊 `applyPlanFold` / `renderPlanOrder` 有 guard（HANDOFF 亦寫明「舊 cache index.html 冇 toggle 就照舊全展開」），day 畫面就冇，同一個 PR 入面唔一致。
- 實測（reviewer）：`git show origin/main:index.html` + 而家嘅 `js/` / `css/` / `locales/` / `data/`，`?preview=plan`，seed 計劃 → `openPlanSchedule()` OK；`openPlanDay(null)` → `Cannot set properties of null (setting 'hidden')`。`showScreen` 已經切咗畫面，所以用戶見到嘅係半渲染日頁（header / pill 有，task 列表同日曆冇更新）。
- 影響：只喺 SW 換版嗰次載入發生（下次載入自動好返）；不過 Home plan 卡「View today's tasks」係常用路徑，而 plan 係 v1.0.x 主打功能。
- 方案 A（推薦）：同 `applyPlanFold` 一樣加 guard——`planShowRest` 開頭 `const emoji = byId('planRestEmoji'); if (!emoji) return;`（舊 shell 照舊顯示圓環 + count，即 v1.0.3 外觀），`planShowMonthNav` `if (!nav) return;`。改動 ~4 行；`upgrade-test` 或 `plan-day-test` 加一個 case：current `index.html` 刪咗呢兩個 element 再 `openPlanDay`，斷言冇 page error、task 列表有渲染。Trade-off：每個新 DOM id 都要記住 guard。
- 方案 B：喺 `utils.js` 加 `setShownIf(id, visible)`（element 唔存在就 no-op），新代碼用佢；或者 `byId` 統一回傳 null-safe proxy。Trade-off：較闊嘅改動，可能掩蓋真正嘅 id 打錯（測試應該捉到但 runtime 唔會出聲）。

### 🟡 W-041 — 已超過 30 行嘅測試函數再加長

- 位置：`tests/plan-day-test.js` `checkPastAndAhead`（35 → 42 行）、`checkLayout`（~62 → ~65 行）

### 🟢 S-125 — `ol.plan-ord-mini` `list-style: none` 喺 Safari / VoiceOver 會失去 list 語意

- 位置：`index.html` `#planOrderMini`、`css/screens/plan.css` `.plan-ord-mini`
- 描述：WebKit 對 `list-style: none` 嘅 `<ol>` / `<ul>` 唔再報做 list（HANDOFF 有 iPhone 實機 check，iOS 係目標平台）。收合 stepper 嘅「第 n 步，共 4 步」資訊會冇咗（編號圓點係 `aria-hidden`）。
- 方案 A（推薦）：`<ol … role="list">`。方案 B：唔 `aria-hidden` `.plan-ord-n`，讓編號讀出。Trade-off：B 會讀「1 Ch 1 Values…」略囉嗦。

### 🟢 S-126 — Stepper / 😴 嘅 px 幾何寫死

- 位置：`css/screens/plan.css` `.plan-ord-mini li + li::before { top: 10px; height: 2px }` 同 `.plan-ord-n { width: 22px; height: 22px }`；`.plan-rest-emoji { font-size: 72px; width: 112px }`
- 描述：`top: 10px` = (22 − 2) / 2，改圓點大細就會錯位；112px 同 `.plan-ring` 重複。
- 方案 A（推薦）：`.plan-ord-mini { --plan-ord-dot: 22px; }`，`top: calc(var(--plan-ord-dot) / 2 - 1px)`；`--plan-ring-size: 112px` 俾 ring 同 emoji 共用。方案 B：註解寫明關係。Trade-off：A 多兩個 custom property。

### 🟢 S-127 — `plan-day-test.js` 註解放錯位置

### 🟢 S-128 — `planShowMonthNav` 嘅 focus 交接分支冇真正被測

- 位置：`tests/plan-day-test.js` `checkSingleMonthCalendar`
- 描述：測試撳日曆格之後斷言 focus 喺 `#planDayHeading`，但 `planShiftDay` / 開日本身已經 focus heading，而 nav 一早已經 hidden，`nav.contains(document.activeElement)` 分支從來冇行過；呢個 assert 拆走 focus 交接代碼都會 pass。

```js
// js/screens/planDay.js
// v1.0.4 (user): a rest day shows a large 😴 (aria-hidden) instead of the ring; its "no tasks" line is only read out
function planShowRest(rest) {
  const emoji = byId('planRestEmoji');
  if (!emoji) return; // an old cached index.html (SW update): keep the v1.0.3 ring + count, no TypeError (W-040)
  byId('planRing').toggleAttribute('hidden', rest); // an <svg> has no .hidden property, so setShown would not apply
  emoji.hidden = !rest;
  byId('planDayHead').classList.toggle('rest', rest); // the rest view's own spacing (plan.css .plan-today-head.rest)
  byId('planDayCount').classList.toggle('plan-sr', rest);
}
function planShowMonthNav(shown) {
  const nav = byId('planCalBtns');
  if (!nav) return; // an old cached index.html: ‹ Today › stays as before (W-040)
  if (!shown && nav.contains(document.activeElement)) byId('planDayHeading').focus({ preventScroll: true });
  nav.hidden = !shown;
}
```
