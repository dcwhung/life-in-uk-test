## 問題清單

### 🟡 W-055 — SW 換版混合頁面顯示 raw key 同一粒死語言掣

- **位置**：`locales/en.js` / `locales/zh-HK.js`（刪咗 `app.langSwitch`、`app.langSwitchLabel`、`common.home`）、`js/core/actions.js`（刪咗 `toggleLang`）、`js/core/i18n.js` `syncLangSetting()`（舊 shell 冇 `#settingsLangRow` 就 return，冇收埋 `#langBtn`）、`css/base/layout.css`（`.lang-btn` 刪咗）
- **描述**：HANDOFF「SW 換版混合頁面」講明舊 SW cache 嘅 `index.html` 可以配新 JS（CUI-0004）。v1.1.x shell 有 `<button class="lang-btn" id="langBtn" data-action="toggleLang" data-i18n="app.langSwitch" …>` 同 7 粒 `data-i18n="common.home"`。新 JS 下：
  - header 右上顯示冇樣式嘅「app.langSwitch」掣，撳落冇反應（只係 `console.warn`）——正正係 W-013 想避免嘅「dead button」；
  - 7 個 screen 嘅返回掣寫「common.home」；
  - 每次 `applyStaticI18n()` 出 10 個 `[i18n] missing key` warning。
  冇 page error，ⓘ 入面嘅 plan switch 照用得。`upgrade-test` ⑥ 改咗用「current shell 減走 ⚙」模擬，冇 case 用真嘅 v1.1.x shell，所以 48/48 PASS 都捉唔到。HANDOFF v1.2.0 行亦冇記錄呢個行為。
- **影響**：每個已安裝用戶升級嗰一次載入有機會撞到（Home 掣係最常用嘅掣，raw key 好核突）；下次載入自己好返。
- **方案 A（推薦）**：開機 shim，舊 markup 就地升級。`js/main.js` `applyLanguage()` 之前 call `adaptLegacyHeader()`（或放 `icons.js`）：
  - `#langBtn` 存在 → `hidden = true`（同 W-013「冇得切就收埋」一致；嗰次載入用唔到切語言，下次載入就有 ⚙）；
  - `.back-btn[data-i18n="common.home"]` → 刪 `data-i18n`、加 `icon-btn` class、`data-icon="home"`、`data-i18n-attr="aria-label:common.homeLabel;title:common.homeLabel"`，之後 `fillStaticIcons()` 照常填 SVG。
  約 10 行；`upgrade-test` 加 ⑧：pin `V112_REF = '44816c6'` 攞 `index.html` + current files，斷言冇 page error、冇 `[i18n] missing key` / `no handler` warning、冇 element 文字符合 `/^[a-z]+\.[A-Za-z.]+$/`、`#langBtn` 冇 client rect、7 粒 Home 掣有 SVG + label。Trade-off：多一段只為舊 shell 而設嘅 code（可以喺 PR-C 或之後一個版本刪，同 `LATE_BOOT_*` 一樣寫明理由）。
- **方案 B**：保留舊 key（`common.home`、`app.langSwitch`、`app.langSwitchLabel`）同 `toggleLang` action 做 legacy alias，`i18n-test` 加 `LEGACY_SHELL_KEYS` whitelist 避開「no unused en keys」。Trade-off：舊 pill 喺混合頁面仲識切語言，但 `.lang-btn` CSS 已刪，佢冇樣式；locale 永遠多咗 3 條死 key，guard 要開例外。
- **推薦**：A。

### 🟢 S-188 — Plan 文字返回掣嘅 `aria-label` / `title` 同可見文字重複，仲失咗 `lang="en"`

- **位置**：`js/screens/planRun.js` `setQuizBackText()`
- **描述**：文字模式（「← Today's tasks」/「← 返去 Day 3」）都 set `aria-label = textContent` 同 `title`。可見文字本身已經係名；`aria-label` 將 `<span lang="en">Day 3</span>` 壓平，zh-HK 讀屏會用中文聲讀「Day 3」，`title` 就多咗一個同文字一樣嘅 tooltip。理解 developer 係想蓋過 `data-i18n-attr` 喺 `setLang()` 時寫返嘅「Home」，不過 `renderQuestion()` 之後一定會 call `renderPlanQuizHeader()`，所以用 remove 都蓋得到。
- **方案 A（推薦）**：文字模式 `back.removeAttribute('aria-label'); back.removeAttribute('title');`，icon 模式先 `setButtonLabel()`。
- **方案 B**：保留 `aria-label`，只刪 `title`。Trade-off：`lang` 問題仍在。

### 🟢 S-189 — ⚙ 開住時變白，mockup 係金色

- **方案 B**：保留白色做「開咗」嘅回饋（ⓘ 嘅 `.open` 都會變色），喺 HANDOFF / mockup 註明。Trade-off：同 mockup 唔一致，要用戶確認。

## 修訂後代碼（建議）

W-055 方案 A（`js/components/icons.js`，`js/main.js` 喺 `applyLanguage()` 之前 call）：

```js
// W-055: an SW cutover can pair a cached v1.1.x index.html with this js (CUI-0004). Its language pill has no handler and
// its Home buttons name removed keys, so upgrade them in place: hide the pill (no ⚙ on that page, as W-013) and turn
// each "← Home" into the 🏠 icon button. Remove once no v1.1.x shell can be cached.
const LEGACY_HOME_SEL = '.back-btn[data-i18n="common.home"]';
function adaptLegacyHeader() {
  const pill = byId('langBtn');
  if (pill) pill.hidden = true;
  document.querySelectorAll(LEGACY_HOME_SEL).forEach(btn => {
    btn.removeAttribute('data-i18n');
    btn.classList.add('icon-btn');
    btn.dataset.icon = 'home';
    btn.dataset.i18nAttr = 'aria-label:common.homeLabel;title:common.homeLabel';
  });
}
```

function setQuizBackText(back, html) {

  back.removeAttribute('title');
}
