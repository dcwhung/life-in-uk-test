#### S-231 — `nowrap` deviation 冇 test 守

- **位置**：`css/screens/plan.css:245`（`.plan-home-head .plan-home-ttl span { white-space: nowrap; }`）；`tests/plan-day-test.js` `checkHomeCard`
- **描述**：HANDOFF 寫「320px 大字『Day 4 / 31』成段落下一行唔會斷開」，但 test 只喺預設 viewport / 細字跑，刪咗呢行 CSS test 都會 PASS。Reviewer probe 確認 320px en 大字而家係成段落第二行。
- **方案 A**：`checkHomeCard` 加一段：`setViewportSize({ width: 320 })` + `setFontSize('large')`，用 `Range.getClientRects()` 驗 `.plan-home-ttl span` 只得一個 line box。Trade-off：要還原 viewport / 字號。
- **方案 B**：只驗 computed `white-space === 'nowrap'`。Trade-off：驗 CSS 唔驗效果。
- **推薦**：A。

#### S-232 — `checkRingTextFits` 幾何寬鬆，✓ 冇驗

- **位置**：`tests/plan-day-test.js` `checkRingTextFits`
- **描述**：分開比 `w ≤ hole`、`h ≤ hole`，等於驗「放唔放得入 49 × 49 正方形」；長方形放入圓要對角線 ≤ 直徑。而家實際對角 44.5 < 49（reviewer 量），所以結果啱，但 margin 只有 4.5 單位，之後加大字號或者改 stroke 會靜靜過 test。✓（`--fs-5xl`）冇驗。
- **方案 A**：`Math.hypot(bb.width, bb.height) <= hole`，迴圈加 `PERCENT`（✓）。Trade-off：bbox 高度係 line box（比 glyph 高），略保守。
- **方案 B**：維持而家，註解寫明係近似。
- **推薦**：A（一行改動）。

#### S-233 — 環內 % 實際字號冇記錄

- **位置**：`css/base/tokens.css:147–149`（`--plan-home-ring-size` 註解）
- **描述**：`--fs-lg` 喺 64-unit viewBox 縮到 56px → 細字約 13.1px、大字約 14.9px（weight 800，9.72:1）。可讀，但「大字模式 +2px」嘅承諾喺呢度實際只係 +1.75px，而且比卡內 `--fs-sm`（12 / 14px）大唔多。之後再縮環就會跌穿 12px。
- **方案 A**：註解寫明實際 px（「% ≈ fs-lg × 56/64」），環尺寸下限留言。
- **方案 B**：`.plan-home-ring-pct` 用 `calc(var(--fs-lg) * 64 / 56)` 補返縮放。Trade-off：要再驗 99% 放唔放得落（大字對角約 50.9 > 49，會超）→ 唔建議。
- **推薦**：A（記錄）。

#### S-234 — `pct` 由 caller 傳入 `planActiveHtml`

- **位置**：`js/screens/planHome.js:117–124`、`:154–164`
- **描述**：`planActiveHtml(plan, log, todayIso, pct)` 自己都 call `planDayAt`，但休息日判斷靠 caller 傳入嘅 `pct`；兩個函數各自計 `planDayAt`。冇 bug，但 `planActiveHtml` 嘅正確性依賴 caller 計啱 `pct`（例如將來喺其他地方 call 唔傳 `pct` → `undefined !== null` → 休息日唔出「Rest day today」）。
- **方案 A**：`pct` 參數冇預設值時 throw 或者自己計：`pct = planHomeTodayPct(plan, log, todayIso)` 做 default parameter。Trade-off：重複計一次（好平）。
- **方案 B**：`planHomeCardHtml` 計一個 `today = { day, pct }` object 傳落兩個函數。Trade-off：簽名改多啲。
- **推薦**：A。

#### S-235 — `pct === null` 等同休息日（既有假設）

```js
// v1.5.1: the widest % ("99%") and ✓ (100) stay inside the 56px ring's hole: en + zh-HK, small + large text.
// A box fits a circle when its diagonal does (S-232)
async function checkRingTextFits(pg) {
  for (const lang of ['en', 'zh-HK']) for (const size of ['small', 'large']) for (const pct of [PERCENT - 1, PERCENT]) {
    const f = await pg.evaluate(([lang, size, pct]) => {
      setLang(lang); setFontSize(size);
      const d = document.createElement('div'); d.className = 'plan-home'; d.innerHTML = planHomeRingHtml(pct);
      byId('planCard').append(d);
      const svg = d.querySelector('.plan-home-ring'), bb = svg.querySelector('.plan-home-ring-pct').getBBox();
      const stroke = parseFloat(getComputedStyle(svg.querySelector('circle')).strokeWidth);
      const out = { diag: Math.hypot(bb.width, bb.height), hole: 2 * PLAN_HOME_RING_R - stroke, px: svg.getBoundingClientRect().width };
      d.remove(); return out;
    }, [lang, size, pct]);
    assert(f.px === 56 && f.diag <= f.hole, `v1.5.1 ${lang} ${size} ${pct}%: text diagonal ${f.diag.toFixed(1)} ≤ ring hole ${f.hole}`);
  }
  await pg.evaluate(() => { setLang('en'); setFontSize('small'); });
}
```
