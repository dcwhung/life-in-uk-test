## 🔴 Critical

### 🔴 C-004 — 有錯題但冇標記時，My Review 喺任何闊度都上下排（inline SVG 令 `textLineCount` 多數一行）

- **位置**：`js/components/fitRow.js:12–16` `textLineCount()`；觸發點 `js/screens/home.js:146` `flaggedTileBody()`（`home.flaggedEmptyHtml` 入面嘅 `bookmarkSvg('bm-inline')`）；`index.html` `.my-grid[data-fit-row]` 包咗 `.my-tile .sub`
- **描述**：`textLineCount` 將 range 入面每個 client rect 嘅 `Math.round(top)` 放入 Set 數。Range 包住元素時，會包埋子元素（SVG）嘅 border box；SVG 用 `vertical-align` 對齊 baseline，top 同文字 rect 差 1px，所以同一行出兩個 top。
- **失敗情境**：用戶答錯 3 題、冇標記任何題（新用戶最常見）。iPad 1024×768 打開 Practice：`#tileFlagged .sub`「Tap 🔖 on a question to flag it」得一行（高 15.4px），但 `textLineCount = 2 > 1` → `.my-grid.is-stacked` → 兩格各佔全闊上下排。v1.3.0 嘅橫向規則係並排，所以係 regression；亦違反 C9「標題一行、說明最多兩行放得落就並排」。zh-HK 一樣。
- **影響**：主頁 My Review 喺最常見嘅狀態下 layout 錯；`fitQuestionCounter` 用同一個 function，日後題號行加 icon 都會中。
- **方案 A（推薦）**：同一行嘅 rect 喺垂直方向重疊；按 top 排序，一個 rect 嘅 top 喺之前所有 rect 嘅 bottom 以下先算新一行（reviewer 已經驗過，見獨立核對）：

  ```js
  // how many lines an element's text runs to (also the C3 quiz counter's check). Rects on one line overlap
  // vertically (an inline icon sits a pixel off the text's top), so a line starts below every rect before it
  function textLineCount(el) {
    const range = document.createRange();
    range.selectNodeContents(el);
    const rects = [...range.getClientRects()].filter(r => r.height).sort((a, b) => a.top - b.top);
    let lines = 0, bottom = -Infinity;
    for (const r of rects) { if (r.top >= bottom - FIT_ROW_LINE_TOL_PX) lines++; bottom = Math.max(bottom, r.bottom); }
    return lines;
  }
  ```
  （`FIT_ROW_LINE_TOL_PX = 1`）。好處：唔再靠 rect top 完全一樣；icon、`<b>`、唔同字號嘅 inline 都 OK。壞處：line-height < 1 嘅字行與行重疊會少數（app 冇咁嘅 CSS）。
- **方案 B**：只量 text node：TreeWalker 逐個 text node `selectNodeContents`，收集 top。好處：完全唔理 icon。壞處：多幾行；一行字分開幾個 text node 時仍然靠 top 一樣（同一 font 冇問題）。
- **推薦**：A。先寫 test：`lang-switch-test` `checkMyReviewFit` 加「`MY_REVIEW_WRONG_N` 錯 + 0 標記」喺 768×1024 / 1024×768 並排（en + zh-HK），舊 code 會 fail。

// how many lines an element's text runs to (also the C3 quiz counter's check). C-004: rects on one line overlap
// vertically (an inline icon sits a pixel off the text's top), so a new line starts below every rect before it
function textLineCount(el) {
  const range = document.createRange();
  range.selectNodeContents(el);
  const rects = [...range.getClientRects()].filter(r => r.height).sort((a, b) => a.top - b.top);
  let lines = 0, bottom = -Infinity;
  for (const r of rects) { if (r.top >= bottom - FIT_ROW_LINE_TOL_PX) lines++; bottom = Math.max(bottom, r.bottom); }
  return lines;
}
