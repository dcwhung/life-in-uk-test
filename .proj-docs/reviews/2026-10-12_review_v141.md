## 問題清單

### 🟢 S-218 — `fontsize-test` S-203 resize 之後用固定 2 個 rAF 等 fit（pre-existing flake）

- **位置**：`tests/fontsize-test.js:261–273`（`checkGoalRefit()` 三次 `setViewportSize` 之後）
- **描述**：resize 之後只等 2 個 animation frame 就讀 `#planLevelGrid.is-stacked`，冇等 `resize` event 真係處理完。
- **影響**：負載高時 full run 偶然 fail「S-203 resize to 320px on the open screen: level cards stack」，單獨跑就過；會令 hard gate 誤報。App 行為冇問題。
- **方案 A**：改用 `pg.waitForFunction(() => byId('planLevelGrid').classList.contains('is-stacked'), null, { timeout: 2000 })`（預期 stacked 嘅三個位）；預期唔 stacked 嘅位保持即時 assert。Trade-off：改動最細；timeout 時 error 訊息要自己包返 assert 字眼。
- **方案 B**：test 入面 resize 之後自己 `dispatchEvent(new Event('resize'))` 再等 2 個 rAF。Trade-off：完全 deterministic，但唔再驗「瀏覽器自己出 resize event」呢條路。
- **推薦**：A（另開一個細 fix，唔阻今次 merge）。
