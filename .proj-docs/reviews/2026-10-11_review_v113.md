### 🟢 Suggestion

#### S-188 —「local council」其他譯法仍然係「地方議會」，同新記憶法 / 4A 撞（diff 以外，之前已存在）

- **位置**：
  - `data/study.js:211` fact #203 `yue`：「城鎮、城市同鄉郊由**民選地方議會**管理……」
  - `data/exams.js` 干擾選項 `oy`：4.19「Manage local councils → 管理地方議會」、5.12「Appointed by the local council → 由地方議會任命」、5.22「The Welsh local council → **威爾斯地方議會**」、11.17 / 15.9「To run local councils → 管理地方議會」
- **描述**：今次刻意用「地區議會」，因為 4A「記憶法（地方議會）」指蘇格蘭 / 威爾斯 / 北愛議會。但 fact #203 自己個 yue（Study 卡上面就係呢段，下面打開 💡 就見到「地區議會」記憶法）同 5 個干擾選項仍然用「地方議會」。最易混淆係 5.22（What is the National Assembly for Wales?）：錯誤選項譯做「威爾斯地方議會」，而同題 4A 記憶法標題正正係「地方議會」、Senedd 一行就係威爾斯，中文模式下呢個錯誤選項讀落似啱答案。
- **影響**：用詞唔一致，學生可能將 local council 同 devolved parliament 混淆；唔影響英文題目或計分。
- **方案 A**：統一將以上 6 處「地方議會」（local council 意思）改做「地區議會」（5.22 可以譯「威爾斯地區議會」）。Trade-off：改 `oy` / STUDY yue，要跑 content-guard 白名單 / 用戶確認字眼，`yue-test` / `oy-test` 可能有 snapshot。
- **方案 B**：只改 fact #203 yue（同記憶法同一張卡，最直接）同 5.22 干擾選項（最易誤導），其餘保留。Trade-off：改得少，但詞彙仍然唔完全一致。
- **推薦**：A，作為獨立內容 follow-up，等用戶決定字眼（今次用戶指明唔改記憶法字，呢度唔應該夾帶落 v1.1.3）。

#### S-189 — test 截圖寫去 cwd、冇 `.gitignore`；誤 commit 嘅 png 仍喺 branch 歷史

- **位置**：`tests/study-test.js:74,104,138` 等 10 個 test（`diff`、`info`、`mastery`、`mode`、`oy`、`similar`、`study`、`subfilter`、`yue`、`yue2`）用 `pg.screenshot({ path: 'shot-*.png' })`；repo 冇 `.gitignore`；a00baab 加咗 5 張共約 433 KB png，7170cd0 刪返，但 branch 已 push 去 `origin/claude/beautiful-mendel-7jgv41`。
- **描述**：路徑相對 cwd，所以喺 repo root 跑個別 test 就會喺 root 出 png，`git add -A` 就會帶埋，即係今次 a00baab 嘅根因。
- **影響**：diff 已經乾淨；但如果用 merge commit / rebase merge，433 KB binary 會永久留喺 main 歷史。以後亦會再發生。
- **方案 A**：merge 時用 squash merge（png 唔會入 main）；另開一個 follow-up 將截圖路徑改做 `path.join(__dirname, 'shot-…png')`。Trade-off：要改 10 個 test 檔；`run-all.sh` 已經喺 `tests/` 入面跑，結果一樣。
- **方案 B**：加 root `.gitignore` 寫 `/shot-*.png`。Trade-off：一行搞掂，但 root 仍然會有雜檔，只係唔會被 commit。
