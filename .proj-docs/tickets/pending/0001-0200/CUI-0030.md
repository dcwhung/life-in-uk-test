## 問題描述

溫習計劃「訂立目標」頁嘅考試日期驗證，喺 Mac Chrome 同 iPad Safari 行為不一致。

- **Mac Chrome**：考試日期少於 7 個溫習日時，「建立進度表」掣 disabled，並顯示紅色錯誤「Fewer than 7 study days, so the plan can't be built」。
- **iPad Safari**：可以將考試日期設為 3 日後（15 Oct 2026），頁面寫「不足」，但文案寫「仍可照樣建立」，「更新進度表」掣可以撳，並真係生成咗 3 日進度表（12/10 開始 · 15/10 考試）。

同一條規則，兩個平台結果唔同，文案亦自相矛盾。

另外，當計劃只有兩個階段（冇 Drill）時，有兩個版面問題：

1. 階段細節卡（Phase detail box）冇用盡闊度，同上方「三個階段」色條（Phase header bar）嘅闊度唔一致。
2. 「Daily tasks」右上 legend 冇 Drill 階段都仍然顯示 Drill。

## 重現步驟

**A. 考試日期驗證（Critical）**

1. 開啟溫習計劃，進入「訂立目標」。
2. 將考試日期設為少於 7 個溫習日後（例：今日 12/10，考試 15/10）。
3. 喺 Mac Chrome 睇結果：Build 掣 disabled，有紅色錯誤。
4. 喺 iPad Safari 重做同一步：可以撳「更新進度表」並生成計劃。

**B. 兩階段版面**

1. 設定目標，令計劃只有「讀 + 練」同「模擬考試」兩個階段（冇 Drill）。
2. 睇「三個階段」色條同下面嘅 Phase detail 卡。
3. 睇 Daily tasks 右上 legend。

## 預期結果

**A.** 考試日期少於 7 個溫習日時，所有平台一致：
- 唔可以建立計劃，掣 disabled，或者
- 容許建立，但文案同行為一致。
（兩個做法要二選一，留待 PM 決定。）

**B1.** 兩個 Phase detail 卡闊度同色條闊度一致，填滿整個闊度。
**B2.** 冇 Drill 階段時，legend 只顯示「Read + practise」同「Mocks」。

## 實際結果

**A.** Mac Chrome 阻擋；iPad Safari 放行，並且文案「不足」同「仍可照樣建立」自相矛盾。
**B1.** Phase detail 卡只佔約 2/3 闊度，右側約 1/3 留空，唔係全寬，同色條唔對齊。
**B2.** Legend 仍然顯示 Drill（紫色）項目。
